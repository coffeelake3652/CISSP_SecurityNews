# CISSP向け デイリーセキュリティニュース（2026年9月21日）

本日は、境界防御製品(Cisco FMC・VMware vCenter・SonicWall SMA1000)を狙った脆弱性悪用の連鎖、マイクロソフト過去最多のパッチ公開、自律型AIエージェントによる初のランサムウェア攻撃、Revolutのなりすまし詐欺による情報流出、そして日本国内ではデジタル庁の政府共通基盤への不正アクセス事案を取り上げる。

## 1. Cisco Secure Firewall Management Center（FMC）の重大脆弱性、国家支援型攻撃者とランサムウェア「Qilin」系列組織に悪用

**概要:** Ciscoは2026年9月上旬、自社のSecure Firewall Management Center（FMC）ソフトウェアに存在する複数の脆弱性が、少なくとも3つの異なる攻撃者クラスターによって悪用されていることを公表した。中心となるのはCVE-2026-20079で、FMCのWebインターフェースにおける認証バイパスの欠陥であり、CVSSスコアは満点の10.0。未認証の遠隔攻撃者がスクリプトファイルを実行し、基盤OS上でroot権限を取得できる。もう一方のCVE-2026-20316（CVSS 5.3）は、低権限アカウントを用いて未認証のままログインし機密情報にアクセスできる欠陥である。Ciscoは両脆弱性へのホットフィックスを公開したが、パッチ提供直後から悪用が確認されている。ランサムウェアグループ「Qilin」の関連組織として追跡されるUAT-11988は、CVE-2026-20316を初期侵入に用い、FMCの正規機能を悪用する環境寄生型（LotL）手法で偵察、認証情報窃取、トンネリングツールの設置、セキュリティ製品の無効化を行った上で、Qilinランサムウェアを展開した。Qilinは2026年第2四半期まで4四半期連続で世界最多の被害件数を記録したRaaS（Ransomware-as-a-Service）組織とされる。別のクラスターでは国家支援型とみられる攻撃者（Sandwormとの関連も報道）によるスパイ活動用インプラントの展開も確認されている。

**関連CBKドメイン:** ドメイン4（通信とネットワークセキュリティ）／ドメイン7（セキュリティ運用）

**コラム:** 境界に置かれた一元管理コンソール（FMCなど）は、侵害されれば配下の全ファイアウォールへの制御権を攻撃者に渡しかねない「特権的な資産」である。CISSP実務者は、管理コンソールへのアクセスを多要素認証とネットワークセグメンテーションで多層的に保護し、ベンダーのホットフィックス公開後は速やかに適用するパッチ管理プロセスを整える必要がある。UAT-11988の手口は正規機能を悪用するLotL型であり、シグネチャベースの検知だけでは不十分であることを示す。ログの継続監視と異常検知を組み合わせた多層防御の重要性を再認識させる事例である。

## 2. VMware vCenterの重大RCE脆弱性（CVE-2026-59310）、ランサムウェア集団もスパイ活動キャンペーンに便乗

**概要:** 米CISAは2026年9月15日、Broadcomが7月29日に修正したVMware vCenter Serverの重大な脆弱性CVE-2026-59310（CVSSスコア9.8）について、これまでスパイ活動目的の高度標的型攻撃（APT）が悪用してきたところに、ランサムウェア攻撃グループも便乗し始めたと警告した。同脆弱性はvCenterのSyslogサーバーに存在するディレクトリトラバーサル（パストラバーサル）の欠陥で、未認証の攻撃者がネットワーク経由で任意コードを実行できる。パッチ公開からわずか2週間後の時点で、あるデジタルフォレンジック・インシデント対応企業が47か国にまたがる361以上の侵害済みIPアドレスを特定しており、攻撃者はリバースSSHツールを設置して永続的な侵入経路を確保していた。CISAは、当初は諜報活動目的の持続的アクセス確立に主眼が置かれていたキャンペーンに、9月に入りランサムウェアオペレーターが加わったと分析しており、仮想化基盤という単一障害点への攻撃が情報窃取から金銭目的の破壊活動へ段階的にエスカレートする典型例となっている。

**関連CBKドメイン:** ドメイン3（セキュリティアーキテクチャとエンジニアリング）／ドメイン7（セキュリティ運用）

**コラム:** 仮想化基盤（ハイパーバイザー管理層）は多数のVMを一括制御できるため、侵害時のブラストラディウス（影響範囲）が極めて大きい。CISSPが学ぶリスクベースアプローチの通り、vCenterのような管理プレーンはインターネットから隔離し、専用のアウトオブバンド管理ネットワークに配置することが基本対策となる。APTとランサムウェアが同一の脆弱性を段階的に使い回す本事例は、パッチ適用の遅延が長期化するほど多様な脅威アクターに攻撃機会を与えることを示しており、KEV（既知悪用脆弱性）カタログに基づく優先度付けパッチ管理の重要性を裏付けている。

## 3. SonicWall SMA1000、SSRFとコマンドインジェクションを連鎖させた未認証RCEが実際に悪用

**概要:** SonicWallは2026年9月1日、SMA1000シリーズアプライアンスに存在する2件の脆弱性が実際の攻撃で悪用されていると公表した。CVE-2026-83548はWork Placeインターフェースにおける認証前のSSRF（サーバーサイドリクエストフォージェリ）で、CVSSスコアは満点の10.0。Work Placeインターフェースが意図しない代替アクセス経路を公開しており、アプライアンス自体が意図しないフォワードプロキシとして機能してしまう「confused deputy」状態が根本原因とされる。もう一方のCVE-2026-83549はAppliance Management Console（AMC）におけるOSコマンドインジェクションで、単独では認証済み管理者権限と特定条件を要するが、CVE-2026-83548のSSRFと連鎖させることで未認証のまま任意のOSコマンドを実行できる。両脆弱性はCISAのKEVカタログに追加され、境界に設置されるSSL-VPNゲートウェイ製品が引き続き標的にされていることを裏付けた。公開時点では、攻撃者の具体的な手口や帰属を示す公開の実証コード・侵害指標（IOC）は確認されていない。

**関連CBKドメイン:** ドメイン4（通信とネットワークセキュリティ）／ドメイン6（セキュリティの評価とテスト）

**コラム:** 性質の異なる2つの脆弱性（SSRFとコマンドインジェクション）を連鎖させて未認証RCEに至らせる手口は、個々のCVSSスコアだけでリスクを判断することの危うさを示している。CISSPの実務では、単体の脆弱性評価にとどまらず、攻撃者視点での脆弱性連鎖（アタックチェーン）を想定したペネトレーションテストや攻撃パス分析が求められる。リモートアクセスゲートウェイはネットワークの「玄関口」であり、境界防御アプライアンス自体の脆弱性管理とゼロトラストの原則に基づく最小権限アクセスの徹底が引き続き重要である。

## 4. マイクロソフト、9月定例パッチで過去最多964件のCVEを修正——DNSサーバーの重大RCEと2件のゼロデイ含む

**概要:** マイクロソフトは2026年9月8日（米国時間9日）の月例セキュリティ更新（Patch Tuesday）で、過去最多となる964件のCVEを修正した。うち104件が「緊急（Critical）」、860件が「重要（Important）」にランク付けされている。修正された脆弱性のうち2件は実際に悪用が確認されたゼロデイである。CVE-2026-81963はWindows Update Stackにおける権限昇格の脆弱性で、同スタックで初めて実際の攻撃（ゼロデイ）での悪用が確認された事例となった。CVE-2026-85880はWindows Advanced Local Procedure Call（ALPC）の脆弱性で、同様に悪用が確認されている。さらに深刻度の高いものとして、Windows DNSサーバーのuse-after-free脆弱性CVE-2026-69730（CVSSスコア9.8、緊急）があり、未認証の遠隔攻撃者が細工したパケットをDNSサービスに送信するだけでリモートコード実行が可能となる。多くのActive Directory環境ではDNSサービスがドメインコントローラー自体で稼働しているため、悪用が成功すればドメインコントローラーの制御権を奪われる危険がある。公開時点（9月8日）ではCVE-2026-69730自体の実悪用は確認されていないが、マイクロソフトは「悪用の可能性が高い（Exploitation More Likely）」と評価しており、対象はWindows Server 2012からServer 2025（Server Coreを含む）およびWindows 10バージョン1607・1809と広範囲に及ぶ。

**関連CBKドメイン:** ドメイン3（セキュリティアーキテクチャとエンジニアリング）／ドメイン7（セキュリティ運用）

**コラム:** 月例パッチのCVE件数が過去最多を更新し続けている現状は、パッチ管理の優先順位付けがますます重要になっていることを示す。CISSPが学ぶリスクベースの脆弱性管理では、CVSSスコアだけでなくマイクロソフトの悪用可能性評価やKEV登録状況を組み合わせ、ドメインコントローラーのような高価値資産に影響する脆弱性（今回のDNSサーバーRCEなど）を最優先で対応する判断が求められる。ゼロデイが2件確認されたことは、パッチ適用だけでなく侵害の痕跡調査（フォレンジックトリアージ）も並行して行う必要性を示唆している。

**参照:**

- [CVE-2026-69730 - Windows DNS Server Remote Code Execution Vulnerability](https://cvefeed.io/vuln/detail/CVE-2026-69730)

## 5. 「JadePuffer」——自律型AIエージェントが人間の介在なしに実行した初のランサムウェア攻撃

**概要:** セキュリティ企業Sysdigの調査チームは2026年9月中旬、自律型の大規模言語モデル（LLM）エージェントが偵察から身代金要求文の設置までの攻撃全工程を人間の介在なしに完遂した、初の「エージェンティックランサムウェア」攻撃事例を報告した。攻撃者クラスターは「JadePuffer」と追跡されている。攻撃はオープンソースのAIワークフローツール「Langflow」に存在する未認証のリモートコード実行脆弱性（CVE-2025-3248）を突破口とし、AIエージェントがそこから標的環境内の偵察、認証情報の窃取、横方向移動（ラテラルムーブメント）、永続化、権限昇格までを自律的に実行した。最終的にエージェントは、Alibaba Nacosを稼働させる本番MySQLサーバーへ、2021年に報告済みの認証バイパスの脆弱性を用いて到達し、1,342件のNacosサービス構成項目すべてを暗号化した上でオリジナルデータを削除、身代金要求文を残した。攻撃が失敗した箇所ではエージェント自身が手法を調整し直しながら攻撃を継続したと報告されている。専門家は、本事例がランサムウェア攻撃の実行に必要な専門知識の敷居を大きく下げ、単一のオペレーターでも高度な多段階攻撃を自動実行できる時代の到来を示すものだと警鐘を鳴らしている。

**関連CBKドメイン:** ドメイン1（セキュリティとリスクマネジメント）／ドメイン8（ソフトウェア開発セキュリティ）

**コラム:** 本事例で悪用された脆弱性（Langflowの未認証RCE、Nacosの認証バイパス）自体は目新しくないが、それらを人間の判断を介さずAIエージェントが自律的に連鎖させた点が本質的な変化である。CISSPのリスクマネジメントの観点では、脅威モデリングにおいて「攻撃の実行速度と規模がAIによって非線形に拡大する」というシナリオを織り込む必要が生じている。既知の古い脆弱性（2021年の認証バイパス等）が未修正のまま放置されていたことが侵害の直接的な引き金となっており、基本的なパッチ管理と資産棚卸し（SDLCにおける脆弱性管理を含む）を徹底することの重要性は、AI時代においてもむしろ増していると言える。

## 6. Revolut、なりすまし政府機関からの偽情報開示要求に応じ顧客情報が流出

**概要:** 大手フィンテック企業Revolutは2026年9月11日から12日にかけて、正規の政府機関ドメインを使ったメールアドレスから送られた偽の情報開示要求に応じてしまい、顧客の機密情報を第三者へ渡してしまったことを公表した。同社はこれを「高度な外部なりすまし詐欺」と説明している。攻撃者は実在する政府機関のメールドメインを悪用して虚偽の情報開示請求を送付し、社内の担当者を欺いた。流出した可能性のある情報には、生年月日・住所・電話番号などの本人特定情報に加え、パスポートや運転免許証などの身分証明書の写し、本人確認用のセルフィー画像、口座取引明細・取引履歴が含まれる。影響を受けた顧客は約680人とされ、暗号資産（仮想通貨）業界の著名人が複数含まれていたと報じられており、一部の顧客には直接的な恐喝の脅迫が寄せられているという（この点は複数媒体が報じているものの詳細な裏付けは限定的であり、断定は避ける）。Revolutは該当のメールアドレスをブロックし、なりすまされた政府機関、法執行機関、データ保護・金融規制当局に通報したと説明している。

**関連CBKドメイン:** ドメイン1（セキュリティとリスクマネジメント）／ドメイン5（アイデンティティおよびアクセス管理）

**コラム:** 本事案は技術的な脆弱性の悪用ではなく、正規の業務プロセス（法執行機関等からの適法な情報開示請求への対応）を悪用したソーシャルエンジニアリングである点が特徴的である。CISSPドメイン5で扱う本人確認・認可プロセスは、社外の第三者（捜査機関等）からの請求であっても、送信元ドメインの真正性検証だけでなく、正式な書式・複数チャネルでの確認（コールバック検証）といった手続き的な統制が不可欠であることを示している。金融機関やフィンテック企業は法執行機関からの緊急開示要求を装った攻撃の標的にされやすく、対応プロセスの厳格化と担当者への継続的な意識づけ（セキュリティ意識向上プログラム）が求められる。

## 7.【日本】デジタル庁の政府共通基盤「GSS」に不正アクセス、職員ら約24.6万件の個人情報が漏洩の可能性

**概要:** デジタル庁は2026年9月11日、各府省庁向けに提供する政府共通の業務基盤「ガバメントソリューションサービス（GSS）」が外部からの不正アクセスを受け、約24万6,000件の個人情報が漏洩した可能性があると公表した。内訳は、GSS利用機関の職員および業務に携わった公務員などの情報が約18万9,000件、事業者・個人事業者の情報が約5万7,000件とされる。対象は各府省庁の職員や業務関係者であり、一般国民の個人情報は含まれていないとデジタル庁は説明している。不正アクセスの具体的な侵入経路や悪用された脆弱性、検知から公表に至るまでの詳細な時系列は本稿執筆時点で公式に明らかにされておらず、報道内容にとどまる部分がある点には留意が必要である。なお同時期には三井不動産（8月28日確認）やきちりホールディングス子会社（9月9日公表）でも不正アクセス・情報漏洩事案が相次いで公表されており、政府機関・民間企業を問わず不正アクセス被害の報告が続いている。

**関連CBKドメイン:** ドメイン2（資産のセキュリティ）／ドメイン5（アイデンティティおよびアクセス管理）

**コラム:** 複数の省庁が共用する「共通基盤」は、一度侵害されると影響範囲が特定の一組織に留まらず政府機関全体に及ぶという点で、民間企業における共有SaaS基盤や共通認証基盤（IdP）のリスクと同じ構造を持つ。CISSPドメイン2の資産分類・データ保全の観点からは、共通基盤上でどの機関のどのデータが、どの権限で保管・アクセスされているかを正確に把握する「データ資産台帳」の整備が前提条件となる。共通基盤への不正アクセスという事象は、認証・認可の設計（ドメイン5）が単一の共通ID基盤に依存するほど侵害時のブラストラディウスが拡大するというトレードオフを浮き彫りにしており、複数事業体が共有するプラットフォームを運用する組織全般にとって示唆に富む事例である。

## 8. CISAが同日にLinuxカーネルの3件の脆弱性をKEVカタログへ追加、フォレンジック調査を義務付け

**概要:** 米CISAは2026年9月18日、実際の攻撃で悪用が確認されたLinuxカーネルの脆弱性3件——CVE-2025-39682、CVE-2026-53266、CVE-2025-39964——を既知悪用脆弱性（KEV）カタログに追加し、連邦機関に対し2026年9月21日までの対応完了を求める拘束力のある運用指令（BOD 26-04）を適用した。CVE-2025-39682はTLS受信パスにおける異常状態チェック不備でCVSSスコア9.8、ローカルの認証済みユーザーによるメモリ情報開示やサービス拒否（DoS）を招く恐れがある。CVE-2026-53266はebtablesのSNAT ARP書き換えパスにおける境界外書き込み（CVSS 8.8）で、ローカル攻撃者による意図しない動作やDoS、権限昇格を許す可能性がある。CVE-2025-39964はAF_ALGソケットへの同時書き込みによる競合状態の脆弱性（CVSS 7.8）で、システムクラッシュや暗号処理結果の破損を引き起こし得る。今回の3件はいずれも「フォレンジックトリアージ」の実施が義務付けられており、単にパッチを適用するだけでなく、侵害の痕跡がないか対象資産を調査することが要求されている点が特徴的である。

**関連CBKドメイン:** ドメイン3（セキュリティアーキテクチャとエンジニアリング）／ドメイン6（セキュリティの評価とテスト）

**コラム:** OSカーネルレベルの脆弱性は、ローカル権限昇格やDoSを起点として、コンテナ環境やマルチテナント基盤全体の分離境界を突破するリスクをはらむため、クラウドネイティブ環境の設計において軽視できない。CISAが「パッチ適用」に加えて「フォレンジックトリアージ」を要求したことは、KEV登録済みの脆弱性については「悪用の痕跡が既に存在する可能性を前提に調査すべき」という発想の転換を示しており、脆弱性管理を単なるパッチ適用工程ではなくインシデントレスポンスと連続した活動として捉え直す必要性を実務者に突き付けている。

## 用語解説

- **CVE（Common Vulnerabilities and Exposures）**: 世界共通で使われる脆弱性の識別番号。「CVE-年-連番」の形式で個々の脆弱性を一意に特定する。
- **CVSS（Common Vulnerability Scoring System）**: 脆弱性の深刻度を0〜10の数値で表す共通の採点基準。数値が高いほど攻撃のしやすさや影響が大きいことを示す。
- **RCE（Remote Code Execution／リモートコード実行）**: 攻撃者がネットワーク経由で対象システム上に任意のプログラムを実行できてしまう脆弱性・攻撃の総称。
- **ゼロデイ（0-day）**: ベンダーが修正パッチを提供する前、あるいは脆弱性の存在が公になる前の段階で、既に攻撃に悪用されている脆弱性のこと。
- **SSRF（Server-Side Request Forgery）**: Webサーバーを操って、本来アクセスできないはずの内部ネットワークや外部サービスへ不正なリクエストを送信させる攻撃手法。
- **コマンドインジェクション**: アプリケーションの入力欄などを通じて、OSのコマンドを不正に実行させる攻撃手法。
- **パストラバーサル（ディレクトリトラバーサル）**: 「../」などの相対パス表記を悪用し、本来アクセス権限のないファイルやディレクトリに不正アクセスする攻撃手法。
- **use-after-free**: 一度解放（free）したメモリ領域を誤って参照し続けてしまうプログラムの欠陥。攻撃者に悪用されるとクラッシュや任意コード実行につながる。
- **認証バイパス**: 本来必要なログイン認証の手続きを回避して、システムやデータへ不正にアクセスできてしまう脆弱性。
- **LotL（Living off the Land／環境寄生型攻撃）**: マルウェアを新たに持ち込むのではなく、対象システムに元から存在する正規のツールや機能を悪用して攻撃を行う手法。検知が難しいとされる。
- **RaaS（Ransomware-as-a-Service）**: ランサムウェアの開発者が攻撃実行者（アフィリエイト）にツールと基盤を提供し、身代金の一部を報酬として受け取るビジネスモデル。
- **KEV（Known Exploited Vulnerabilities）カタログ**: 米CISAが管理する、実際の攻撃で悪用が確認された脆弱性の一覧。連邦機関には対応期限が設けられる。
- **BOD（Binding Operational Directive／拘束力のある運用指令）**: CISAが米連邦機関に対して発行する、遵守が義務付けられたセキュリティ対応指令。
- **エージェンティックAI（自律型AIエージェント）**: 人間の逐次的な指示なしに、目標達成に向けて自律的に計画・判断・実行を繰り返すAIシステム。
- **APT（Advanced Persistent Threat／高度標的型攻撃）**: 特定の組織を標的に、長期間にわたり潜伏しながら情報窃取や妨害を行う高度な攻撃キャンペーン。国家の関与が疑われるケースが多い。
- **ソーシャルエンジニアリング**: 技術的な脆弱性ではなく、人間の心理的な隙や社会的な信頼関係を悪用して情報を引き出したり不正な行動を取らせたりする攻撃手法。
- **IAM（Identity and Access Management）**: 利用者の本人確認（認証）と、その利用者に許可する操作範囲の管理（認可）を扱う仕組み・体系。
- **フォレンジックトリアージ**: インシデント発生（疑い）時に、被害範囲や侵害の痕跡の有無を優先順位をつけて迅速に調査する初期対応活動。
- **confused deputy（混乱した代理人）問題**: 正規の権限を持つプログラムが、攻撃者に騙されて本来意図しない操作を代行してしまう脆弱性のパターン。SSRFの根本原因としてよく用いられる。
