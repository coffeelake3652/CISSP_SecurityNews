## 1. Polymarket、第三者スクリプト（DebugBear）の乗っ取りで約270万ドルが流出 — レジストラ経由のDNS侵害によるサプライチェーン攻撃

**概要**
2026年10月29日、暗号資産予測市場Polymarketのサイトが読み込んでいた、リアルユーザーモニタリング（RUM）ベンダーDebugBearのページ速度計測スクリプトが悪意あるコードに差し替えられた。報道によれば原因はDebugBearのドメイン登録事業者（レジストラ）経由でDNSレコードが侵害されたことで、DebugBear自身のシステムへの侵入はなく、特定の1顧客サイトを狙った攻撃と初期調査では見られている。差し替えられたスクリプトはログイン済みの取引画面内で動作し、ブラウザ内に保持されたアカウント情報（取引用APIキー等）を読み取り、注文送信コードと署名処理を特定して悪用した。ウォレット認証のアカウントではポジションが攻撃者ウォレットへ直接移され、メール認証のアカウントではポジションが段階的に不利な価格で売却され代金が持ち出された。時系列（UTC）は、17:10に攻撃者ウォレットへ最初の入金、17:38にPolymarketが最初の障害告知、18:05に取引所が「キャンセルのみ」モードへ移行、18:28〜18:38に28.6百万POLが3アドレスへ移動。被害は726ウォレット・約270万ドルで、Polymarketは返金総額390万ドル（取引停止中の損失等で約5,500ウォレットに119万ドルを含む）を表明し、10/30時点で726件中689件が全額返金済み。Hudson Rockの分析ではキーやシードフレーズを外部送信するコードは見つかっていない。Polymarketは今後、サードパーティスクリプトを再導入する際にCSP強化・バージョン固定・サンドボックス化を行う方針。攻撃者は未特定（情報源は主にThe Hacker News、単一情報源）。

**コラム**

## 2. Teams上のIT担当なりすまし＋AD CS（ESC1/ESC8）悪用で特権奪取 — Microsoftが2件の侵入を報告

## 5. Canonical LXD / MicroCloud に CVSS 10.0（CVE-2026-112816）— 秘密鍵なしで信頼済みクライアントになりすまし可能

**概要**
2026年11月1日、CanonicalはLXDおよびMicroCloudの脆弱性CVE-2026-112816（CVSS 10.0）を公表した。サーバーはクライアントが提示した証明書チェーンの各証明書を信頼ストアと照合していたが、TLSハンドシェイクが証明するのはリーフ証明書の秘密鍵の保持のみである。そのため攻撃者は、秘密ではない信頼済みクライアントの公開証明書を自分の証明書の後ろに付加するだけで受理され、そのクライアントの権限（クラスタ・VM操作、特権アカウントならホストのroot権限）を得られる。前提条件はHTTPS APIへのネットワーク到達性と標的の公開証明書で、スタンドアロンLXDは既定でAPIを公開せず `core.https_address` の設定が必要。MicroCloudではクラスタ参加時に他メンバーの公開証明書を取得できれば成立する。影響はLXD 4.0.14、5.0.10、5.21.8、6.9（各修正前）で、修正版はLXD 6.10.1／5.21.9／5.0.11／4.0.15、MicroCloud 3.4.1／2.1.5。コミュニティフォークのIncusが報告し7.6.0で修正した。公開時点でsnapチャネルへの反映途中であり、更新後にバージョン確認が必要とされる。10/30付のCISA評価では悪用は未確認でKEV未掲載、実用的なエクスプロイトも未公開。一時的な回避策はなく、APIへのアクセス制限が唯一の緩和策。

**関連CBKドメイン**: ドメイン3（セキュリティアーキテクチャとエンジニアリング）、ドメイン5（アイデンティティおよびアクセス管理）、ドメイン4（通信とネットワークセキュリティ）

**コラム**
相互TLS認証で「証明書の提示」と「秘密鍵の所持証明」を混同した実装ミスであり、ドメイン3の暗号・PKIの正しい利用（検証対象と信頼の根拠の区別）を問う教材として典型的である。ドメイン5では、公開情報である証明書を「資格情報」と同一視してはならない点、証明書ピン留めや信頼ストアの設計を再確認する契機になる。ドメイン4の観点からは、管理APIを信頼できるセグメントへ限定する多層防御が、深刻な認証欠陥に対する最後の防波堤となる。未悪用の段階でも、仮想化基盤はクラウド/オンプレの要であるため、パッチ適用の優先度を高めて計画すべきである。

## 用語解説

- **RUM（Real User Monitoring）**: 実際の利用者のブラウザから表示速度などの性能データを収集する仕組み。通常はベンダー提供のスクリプトをページに読み込ませる。
- **サプライチェーン攻撃**: 標的組織そのものではなく、取引先・ベンダー・ソフトウェア部品を侵害して間接的に攻撃する手法。
- **レジストラ**: ドメイン名の登録・管理を行う事業者。ここが侵害されるとDNSレコードを書き換えられる。
- **DNS**: ドメイン名をIPアドレスに対応付ける仕組み。
- **CSP（Content Security Policy）**: ブラウザに読み込みを許可するスクリプトや通信先を制限するHTTPヘッダー。
- **SRI（Subresource Integrity）**: 外部ファイルのハッシュ値を指定し、改ざんされたファイルの読み込みを拒否する仕組み。
- **POL**: Polygonネットワークの暗号資産（トークン）。
- **Quick Assist**: Windows標準のリモート支援ツール。接続コードで他人に画面共有・操作を許可できる。
- **Active Directory / AD CS（Active Directory証明書サービス）**: Windows環境のID管理基盤と、その上で証明書を発行するPKIサービス。
- **ESC1 / ESC8**: AD CSの設定不備に基づく攻撃類型。ESC1は申請者が証明書の対象アカウントを自由に指定できるテンプレートの悪用、ESC8はNTLM認証をWeb登録エンドポイントへリレーして証明書を取得する攻撃。
- **PetitPotam**: Windowsサーバーを攻撃者のマシンへ強制的に認証させる手法・ツール。
- **NTLMリレー**: 取得したNTLM認証を別のサーバーに中継してなりすます攻撃。
- **EPA（Extended Protection for Authentication）**: 認証を通信経路に結び付けてリレー攻撃を防ぐ保護機能。
- **PKINIT**: Kerberos認証で証明書を使って初期認証を行う拡張。
- **TGT（Ticket Granting Ticket）**: Kerberosで発行される、他のサービスチケットを得るための基本チケット。
- **DCSync**: ドメインコントローラの複製機能を装い、パスワードハッシュ等を取得する攻撃手法。
- **Rclone**: クラウド/リモートストレージとファイルを同期するツール。データ持ち出しにも悪用される。
- **SFTP**: SSH上で動作するファイル転送プロトコル。
- **Defender automatic attack disruption**: Microsoft Defenderが攻撃を検知した際、侵害されたアカウントや端末を自動で遮断する機能。
- **NAS**: ネットワーク経由で使うファイルサーバー専用機器。
- **DSM**: SynologyのNAS向けOS（DiskStation Manager）。
- **ランサムウェア**: データを暗号化して身代金を要求するマルウェア。
- **Shadowserver**: インターネット上の脆弱・露出機器を調査・公開する非営利団体。
- **Langflow / MCP（Model Context Protocol）**: LangflowはAIワークフローをGUIで構築するOSS。MCPはAIアプリと外部ツール/データを接続する標準プロトコル。
- **Metasploit**: 脆弱性の検証・攻撃用モジュールを提供するフレームワーク。
- **CVSS**: 脆弱性の深刻度を0〜10で表す共通指標。
- **CISA KEV（Known Exploited Vulnerabilities）**: 米CISAが管理する、悪用が確認された脆弱性のカタログ。
- **RCE（リモートコード実行）**: 外部から任意のコードを実行できる脆弱性。
- **LXD / MicroCloud / Incus**: LXDはLinuxのコンテナ/VM管理ツール、MicroCloudはその小規模クラスタ構成、IncusはLXDのコミュニティフォーク。
- **snap**: Ubuntu系で使われるパッケージ配布形式。
- **相互TLS（mTLS）/ リーフ証明書**: クライアントとサーバーが互いに証明書で認証するTLS。リーフ証明書は証明書チェーンの末端の証明書。
- **SaaS**: ソフトウェアをインターネット経由で提供するサービス形態。
- **Cuenote FC / Cuenote BASE**: ユミルリンクのメール配信サービスと顧客管理サービス。
- **CL-UNK-1211**: Unit 42が付けた、所属未確定の攻撃クラスタ識別名。
- **RAT**: 遠隔操作型マルウェア。
- **WebSocket**: 双方向通信を行うWeb向けプロトコル。C2通信にも使われる。
- **C2（コマンド&コントロール）**: 攻撃者がマルウェアに指令を送るサーバー。
- **Webシェル**: サーバー上に置かれ、Web経由で遠隔操作を可能にする悪意あるスクリプト。
- **SBOM**: ソフトウェアの構成部品一覧。脆弱性の影響調査に使う。
- **バグバウンティ**: 脆弱性を報告した研究者に報奨金を払う制度。
- **XCPE / ボットネット**: 乗っ取られた多数の機器から成る攻撃用ネットワークと、その名称。
- **インフォスティーラー**: パスワードやCookieなどの情報を盗むマルウェア。
- **SOC**: セキュリティ監視・対応を行う組織/機能。
