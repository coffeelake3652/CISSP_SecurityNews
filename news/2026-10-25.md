**概要**

## 2. Nextcloud 内蔵「Collabora Online – Built-in CODE Server」に未認証OSコマンドインジェクション（CVE-2026-110447）: 実被害を受けCISA KEVに追加

**概要**
Nextcloud の `richdocumentscode` アプリ（Collabora Online 内蔵CODEサーバー）の `proxy.php` に、未認証のOSコマンドインジェクション（CVE-2026-110447、CVSS v4.0 9.2）が存在する。コマンドはWebサーバー権限で実行され、内蔵CODEサーバーが「起動していない間（再起動・アップグレード・クラッシュ時）」にのみ悪用可能という条件付きだが、2026年9月〜10月に実環境での悪用が確認され、PHP Webシェルの設置や設定情報・シークレットの窃取が報告されている。影響は 26.4.303 未満の内蔵アプリで、修正版 26.4.303 は 2026-09-11 に公開された（Nextcloud 30以降が必要で、29以下は適用不可）。CVE/アドバイザリの公開は 2026-10-14、CISA KEV追加は 2026-10-23、連邦機関の対応期限は 2026-10-26 とされる。攻撃は9月10日頃に始まったとの未確認の報告があり、攻撃者・グループは特定されていない。スタンドアロンのCollabora Online、Dockerイメージ、RPM/DEB、Nextcloud All-in-One、ホスト型サービスは影響を受けないとされる。対策はアプリ更新または削除、不審なPHPファイル・`proxy.php` へのリクエスト確認、認証情報のローテーションで、侵害が疑われる場合はホストの再構築が推奨される（二次情報源中心）。

## 3. 【国内】WAF「SiteGuard Server Edition」にOSコマンドインジェクション（CVE-2026-106931）: 悪用確認、JPCERT/CCが注意喚起しKEV追加

**概要**

**コラム**

## 8. 【国内】日本関連のサイバー攻撃報告が2026年Q3に918件（Q2比+48%）: 個人情報を狙う攻撃が急増、積極的サイバー防御関連の報告義務も開始

**概要**
Recorded Future の Insikt Group が 2026-10-22 に公表した報告「Behind Japan's Warnings of a Cyber Crisis」によれば、日本関連の攻撃報告は2026年第3四半期に918件で、第2四半期の621件から48%増加した（Mynavi TECH+ が 10/25 に報道。単一情報源に近い）。Trend Micro のデータでは2026年1〜9月の国内攻撃件数が2025年通年を超え、9月単独で86件、Macnica は2026年の公開された個人情報漏えいを119件と集計し、その約68%が7月以降に発生したとしている。主な事例として、7月の「EPARK PeakManager」約3,300万件の漏えい、9月のタイムズカー約660万アカウント、10月の IDC フロンティアへのランサムウェア、Sourcenext での不正なAPI利用による顧客データ露出が挙げられている。業種は小売、鉄道、物流、メディア、教育、ソフトウェアに広がり、手口はランサムウェア、クラウド認証情報の窃取、インターネット公開システムの脆弱性悪用である。背景として、日本の個人情報がダークウェブで高値で取引されること、60%超の企業でレガシーシステムが残ること、2026-10-01 施行の能動的サイバー防御関連の報告義務により公表件数が増える可能性が挙げられている。Recorded Future は、報告件数の増加が実際の攻撃の比例的増加を意味するとは限らないと注意している。
**関連CBKドメイン**: ドメイン1（セキュリティとリスクマネジメント）、ドメイン2（資産のセキュリティ）、ドメイン5（アイデンティティおよびアクセス管理）
**コラム**
報告義務の開始により「見える化」が進む局面では、統計の増加を脅威の増加とそのまま解釈せず、測定方法の変化を踏まえて評価するというリスク分析の基本が問われる（ドメイン1）。流出規模が数百万〜数千万件に達する事例が続く背景には、不要な個人データの長期保管があり、データ最小化・保持期間管理・データ分類（ドメイン2）が最も確実な被害縮小策である。APIの認可不備による漏えいが目立つため、APIのレート制限、最小権限のトークン、フィッシング耐性MFA（ドメイン5）を点検項目に加えたい。

## 用語解説

- **RCE（リモートコード実行）**: 攻撃者が遠隔から対象システム上で任意のプログラムを実行できる脆弱性・状態。
- **CVE / CVSS**: CVEは脆弱性の共通識別番号、CVSSは深刻度を0〜10で表す共通評価方式（9.0以上は「重大」）。
- **CISA KEV**: 米CISAが管理する「悪用が確認された脆弱性」の一覧。連邦機関に修正期限が設定され、民間の優先度判断にも使われる。
- **SSRF（サーバーサイド・リクエスト・フォージェリ）**: サーバーを踏み台にして、本来アクセスできない内部リソースや任意のURLへリクエストを送らせる攻撃。
- **脆弱性の連鎖（チェイニング）**: 単体では限定的な複数の脆弱性を組み合わせ、より深刻な結果（未認証RCEなど）を得る手法。
- **ELF**: Linuxで使われる実行ファイル/共有ライブラリの形式。
- **XMRig / クリプトマイナー**: 他人の計算資源で暗号資産（Monero）を採掘するソフトウェア。
- **リバースプロキシ型バックドア**: 侵害したホストから攻撃者のサーバーへ接続させ、通信の中継や遠隔操作に使う仕組み。
- **ボットネット（AISURU）**: 乗っ取った多数の機器で構成されるネットワーク。DDoS攻撃やプロキシ提供に使われる。
- **Webシェル**: Webサーバー上に設置される、遠隔操作用の小さなスクリプト。
- **OSコマンドインジェクション**: 入力値を通じて、サーバー上のOSコマンドを実行させる攻撃。
- **WAF（Webアプリケーションファイアウォール）**: Webアプリケーションへの攻撃（SQLインジェクション等）を検査・遮断する防御製品。
- **フォレンジック／痕跡保全**: インシデント調査のため、ログやメモリ等の証拠を改変しないよう保全すること。
- **CPU（クリティカルパッチアップデート）**: Oracleが四半期ごとに公開するセキュリティ修正の一括配布。
- **ERP / EBS**: ERPは基幹業務統合システム。EBSは Oracle E-Business Suite、その代表製品の一つ。
- **IAM / Oracle Access Manager**: IAMは識別・認証・認可を管理する仕組み。Access Managerは Oracle のアクセス管理製品。
- **SOA Suite / T3 / IIOP**: SOA SuiteはOracleのシステム連携基盤。T3・IIOPはJava系ミドルウェア間で使われる通信プロトコル。
- **認証バイパス**: 正規の認証手続きを経ずにシステムへアクセスできてしまう欠陥。
- **SQLインジェクション**: 入力値経由でデータベースへの命令（SQL）を不正に実行させる攻撃。
- **バッファオーバーフロー**: 想定以上のデータをメモリ領域に書き込むことで、プログラムを乗っ取る欠陥。
- **PAPI**: Aruba機器が内部で使う管理用の独自プロトコル。
- **VLAN / レイヤ2セグメント**: ネットワークを論理的に分離する仕組み。管理用通信の隔離に使う。
- **アフィリエイト（ランサムウェア）**: ランサムウェアの開発者から基盤を借りて攻撃を実行し、収益を分配する実行犯。
- **EDR / BYOVD**: EDRは端末の不審な挙動を検知・対応する製品。BYOVDは脆弱な正規ドライバーを持ち込み、カーネル権限でEDRを停止させる手口。
- **C2（コマンド＆コントロール）**: 侵害した端末へ攻撃者が指令を出す通信基盤。
- **MCP（Model Context Protocol）**: AIモデルが外部ツールやデータに接続するための標準的な仕組み。
- **ペネトレーションテスト（AIペンテスト基盤）**: 疑似攻撃で弱点を探す検査。その自動化ツールが攻撃者に悪用される事例が出ている。
- **WSUS**: Windowsの更新プログラムを社内で配布する管理サーバー。
- **初期アクセスブローカー（IAB）**: 侵入済み環境へのアクセス権を他の攻撃者に販売する犯罪者。
- **LDAP**: ディレクトリ（ユーザー情報）を照会・認証するための通信プロトコル。
- **最小権限／多層防御／データ最小化**: 必要最小限の権限・データだけを与える原則／複数の防御を重ねる考え方／不要な個人データを持たない方針。
- **フィッシング耐性MFA**: FIDO2/パスキーなど、偽サイトでは使えない多要素認証。
- **ランサムウェア**: データを暗号化・窃取して身代金を要求するマルウェア。
- **ダークウェブ**: 通常の検索では到達しにくく、不正データの取引にも使われるネットワーク領域。
- **能動的サイバー防御**: 日本の新制度。重要インフラ等の被害報告義務や、政府による事前の対処を含む。
- **シャドーIT**: 組織の管理外で使われる機器・サービス。
- **サンドボックス（エスケープ）**: プログラムを隔離実行する仕組み。そこから脱出して外部に影響を及ぼすのがエスケープ。
- **レース条件**: 処理のタイミング次第で結果が変わり、特定の状態で欠陥が突かれる問題。
