## 1. Citrix NetScaler の既知脆弱性（CVE-2026-8452）が悪用され、CISAが緊急パッチ指令

**概要**: Citrix NetScaler ADC/Gateway製品に存在するメモリオーバーフローの脆弱性CVE-2026-8452が、パッチ公開後にもかかわらず実際の攻撃に悪用されていることが判明した。Citrixは2026年6月30日に脆弱性を公表し、同日にバージョン14.1-72.61、13.1-63.18、13.1-37.272で修正パッチを提供済みだったが、パッチ未適用の環境が標的となった。セキュリティ企業WatchTowrの分析により、本脆弱性は認証不要のリモートコード実行（RCE）に悪用可能であることが実証されている。攻撃者は侵害後、「x.php」「z.php」という名前のWebシェルを設置し、「id」「echo」などの偵察コマンドを実行して侵害範囲を把握していたことが確認された。影響を受けるのは、SSL VPN・ICA Proxy・CVPN・RDP Proxyとして構成されたGatewayモード、またはAAA仮想サーバとして構成されたNetScaler機器である。CISAは2026年8月26日にアラートを発出し、連邦機関に対して8月29日までの修正を義務付ける緊急指令を出した。

**関連CBKドメイン**: ドメイン4（通信とネットワークセキュリティ）、ドメイン6（セキュリティの評価とテスト）、ドメイン7（セキュリティ運用）

**コラム**: 本件はVPNゲートウェイという「境界防御の要」が攻撃対象となった典型例であり、ドメイン4のネットワークセキュリティに直結する。同時に、パッチ公開から約2か月後に悪用が確認された事実は、脆弱性管理（パッチマネジメント）というドメイン7の実務がいかに重要かを物語っている。「パッチが出ている＝安全」ではなく、パッチ適用の遅延そのものがリスクであるという原則をCISSP実務者は常に組織に説明する必要がある。CISAのKEV（Known Exploited Vulnerabilities）カタログへの追加とタイムラインを継続的に監視し、境界機器を優先度の高い資産として脆弱性スキャン（ドメイン6）の対象に含めることが望ましい。

## 2. Cl0pランサムウェア、PTC Windchill/FlexPLMの脆弱性（CVE-2026-12569）を悪用し40社以上を被害公表

**概要**: ランサムウェア（正確にはデータ窃取・恐喝型）集団Cl0pが、製品ライフサイクル管理（PLM）製品であるPTC WindchillおよびFlexPLMの脆弱性CVE-2026-12569を悪用したキャンペーンで、Shell、Philips、Fiserv、Zebra、Mindray、Largan Precisionなど40社以上をリークサイトに公表した。この脆弱性は不適切な入力検証に起因し、未認証のリモート攻撃者が細工したリクエストを送ることで任意コード実行を可能にするもので、Windchill製品として初めて実際の攻撃に悪用された事例となった。攻撃者はFlexPLMのWSDLエンドポイントにおける認証前の情報漏洩と、Windchillログインサーブレットのサーバサイド脆弱性を連鎖させ、16進数名のJSP Webシェルを設置して未認証RCEを達成する手法を用いた。脆弱性は2026年6月にCISAのKEVカタログに追加され、ベンダーからも攻撃に関する注意喚起が出されていた。被害業種は製造業、自動車、航空宇宙、小売・アパレルなど多岐にわたり、Cl0pは典型的にデータを暗号化せず窃取のみを行い、公開を材料に金銭を要求する「exfiltration-only」モデルを採用している。

**関連CBKドメイン**: ドメイン1（セキュリティとリスクマネジメント）、ドメイン4（通信とネットワークセキュリティ）、ドメイン7（セキュリティ運用）

**コラム**: PLMシステムは設計図面や知的財産といった機密性の高いデータを保持するため、侵害の影響は製品セキュリティや競争優位性そのものに及ぶ。サプライチェーン上の一つのソフトウェア脆弱性が業種を超えて40社以上に波及した点は、サードパーティリスクマネジメント（ドメイン1）の重要性を改めて示している。また「暗号化なしのデータ窃取のみ」という恐喝モデルは、バックアップの整備だけでは対策として不十分であることを意味し、インシデント対応計画（ドメイン7）ではデータ漏洩そのものを前提とした対応手順の整備が求められる。インターネットに露出したPLM・ERPなど業務システムの棚卸しと露出面の縮小も合わせて検討すべきである。

## 3. Windows AFD.sysのゼロデイ（CVE-2026-68820）、北朝鮮系Lazarusが防衛関連企業を標的に悪用

**概要**: Windows Ancillary Function Driver for WinSock（AFD.sys）に存在する権限昇格の脆弱性CVE-2026-68820（CVSSスコア7.0）が、パッチ提供前から実際の攻撃に悪用されていたことが判明した。本脆弱性は複数スレッドがソケット関連の状態に同時アクセスする際の同期処理不備に起因するuse-after-free（解放済みメモリの再利用）であり、特定の競合状態（レースコンディション）を突くことでカーネルメモリへのアクセスと、SYSTEM権限への昇格が可能となる。Check Point Researchの分析により、北朝鮮に関連するとされるLazarusグループが、長期展開している「Operation Dream Job」の一環として2026年7月初旬から少なくとも5週間にわたり本脆弱性を悪用し、防衛関連企業の従業員を標的にしていたことが特定された。侵害に成功した場合、攻撃者はシステムを完全掌握し、ForestTigerバックドアを展開していたとされる。Microsoftは2026年8月11日のPatch Tuesdayで修正パッチを提供し、CISAはKEVカタログに追加のうえ連邦機関に2週間以内のパッチ適用を求めた。

**関連CBKドメイン**: ドメイン3（セキュリティアーキテクチャとエンジニアリング）、ドメイン7（セキュリティ運用）、ドメイン1（セキュリティとリスクマネジメント）

**コラム**: カーネルドライバのuse-after-freeという極めて技術的な脆弱性が、国家支援型アクターによる長期スパイ活動に悪用された事例であり、ドメイン3で学ぶメモリ安全性やセキュアな設計原則の重要性を裏付ける。防衛産業のような特定セクターが標的とされる点は、脅威インテリジェンスに基づくリスクベースの防御優先度付け（ドメイン1）の必要性を示す。ゼロデイである以上、パッチ適用だけでは侵害を防げなかった実例であり、EDR（エンドポイント検知・対応）による異常な権限昇格挙動の検知や、最小権限原則の徹底といった多層防御（ドメイン7）が補完的に不可欠である。

## 4. Microsoft SharePointの認証バイパス（CVE-2026-55040）、PoC公開後に悪用が急拡大

**概要**: Microsoft SharePointに存在する認証不備の脆弱性CVE-2026-55040（CVSSスコア9.1）が、実証コード（PoC）の公開直後から実際の攻撃に悪用されていることが確認された。本脆弱性はJWT（JSON Web Token）検証処理における4つの弱点を連鎖させるもので、未認証のリモート攻撃者が正当なJWTを偽造し、任意のSharePointサイトユーザーになりすますことを可能にする。2026年8月11日にRapid7が技術詳細を公開したところ、数時間後にはパッチ未適用のオンプレミスSharePointサーバに対する実際の悪用が観測され始めた。この事態を受けCISAは同月18日、本脆弱性をKEVカタログに追加した。SharePointは同時期に他の複数の脆弱性（VMware vCenterのパストラバーサル脆弱性CVE-2026-59310、CVSSスコア9.8を含む）とあわせて「積極的に悪用されている重大脆弱性」として報じられており、vCenter側では47か国361の侵害済みIPアドレスが確認されている。

**関連CBKドメイン**: ドメイン5（アイデンティティおよびアクセス管理）、ドメイン6（セキュリティの評価とテスト）、ドメイン3（セキュリティアーキテクチャとエンジニアリング）

**コラム**: JWTのなりすましによる認証バイパスは、まさにドメイン5が扱うアイデンティティ検証の根幹に関わる脆弱性である。トークンベース認証を採用するシステムでは、署名検証・有効期限・発行者検証などの実装不備が容易に権限昇格へつながることを、CISSP実務者は設計レビューの段階で重点的に確認すべきである。またPoC公開から悪用開始までがわずか数時間だったという事実は、脆弱性対応のリードタイムが劇的に短縮している現状を示しており、CVSSスコアや脅威インテリジェンスに基づく優先度付けパッチ管理（ドメイン6）を「月次」ではなく「即応」で回せる体制の整備が急務であることを裏付けている。

## 5. Medusaランサムウェア、被害500組織超に。FBI・CISA・HHSが合同勧告を更新

**概要**: FBI、CISA、および米保健福祉省（HHS）は2026年8月18日、ランサムウェアグループ「Medusa」に関する合同サイバーセキュリティ勧告（#StopRansomware）を更新した。同勧告によれば、2026年4月時点でMedusaは医療・公衆衛生、防衛産業基盤、重要製造業、政府サービス・施設、情報技術、金融サービスなど複数の重要インフラ分野で500組織以上に被害を及ぼしている。特に医療機関が最も攻撃密度の高い標的となっているため、今回初めてHHSが勧告の共同発行者に加わった。Medusa actorsはアクセスブローカー経由の侵入、フィッシング、公開直後でパッチ未適用の脆弱性の悪用など複数の手口で初期侵入を果たし、正規の管理ツールを悪用する「Living off the Land」手法や、RDP（リモートデスクトッププロトコル）を用いた侵害環境内の横展開を行う。手口はシステム暗号化とデータ窃取を組み合わせた二重恐喝モデルで、身代金を支払わない場合は窃取データの公開を脅す。勧告では、既知脆弱性へのリスクベースのパッチ適用、多要素認証の導入、ネットワークセグメンテーションなどが推奨されている。

**関連CBKドメイン**: ドメイン1（セキュリティとリスクマネジメント）、ドメイン7（セキュリティ運用）

**コラム**: 500組織超という規模と医療機関への集中は、重要インフラに対するランサムウェアが人命にも関わるリスクへと発展し得ることを示しており、リスクアセスメントの優先順位付け（ドメイン1）において医療・重要インフラセクターが引き続き最重要標的であることを裏付ける。Living off the Land手法の多用は、マルウェア検知だけに依存したセキュリティ運用（ドメイン7）の限界を意味し、正規ツールの異常な使用パターンを検知するふるまい分析やログ監視の強化が求められる。CISSP実務者は、公式勧告に示されたTTP（戦術・技術・手順）を自組織の検知ルールやインシデント対応演習に反映させる「脅威インテリジェンスの実務への落とし込み」を継続的に行う必要がある。

## 6. ニチレイへのサイバー攻撃、RansomHouseが20万件超のデータを公開と主張

**概要**: 冷凍食品大手ニチレイは2026年7月15日、自社サーバがサイバー攻撃を受けたことを確認し、被害サーバの一部に個人情報が保管されていたことから個人情報保護委員会へ漏えいの可能性がある事案として報告した。この影響で出荷・受注業務が一時停止するなど事業運営にも支障が生じた。ランサムウェア集団を名乗る「RansomHouse」は、ニチレイのデータを暗号化し窃取の証拠を得たと主張したうえ、8月10日午前にダークウェブ上で少なくとも20万件超とされるファイルを公開した。公開されたデータには、ニチレイの従業員や取引先の氏名・生年月日・社用メールアドレス・従業員番号・人事労務情報、電話番号などの個人情報が含まれるとされる。ニチレイは8月14日、従業員の個人情報が漏えいした恐れがあると正式に発表した一方、同グループの関与、ランサムウェアによる暗号化、データ窃取の事実そのものは公式には確認していない状態が続いている。

**関連CBKドメイン**: ドメイン1（セキュリティとリスクマネジメント）、ドメイン2（資産のセキュリティ）、ドメイン7（セキュリティ運用）

**コラム**: 出荷・受注業務の停止という事業影響は、サイバー攻撃が単なる情報漏えいにとどまらず事業継続（BCP）に直結するリスクであることをドメイン1の観点から示している。人事労務情報を含む従業員データが標的となった点は、データ分類とアクセス制御（ドメイン2）の観点から、機密性の高い人事系データを保管するシステムの防御優先度を見直す必要性を示唆する。また「攻撃者の主張と企業の公式確認に食い違いがある」状態は日本のインシデント対応で頻繁に見られる構図であり、単一情報源の情報を鵜呑みにせず、フォレンジック調査に基づく事実確認を経てから対外説明を行う体制（ドメイン7）の重要性を再確認させる事例である。

## 7. さくらインターネット「さくらのレンタルサーバ」に不正アクセス、最大136万アカウントに影響の可能性

**概要**: さくらインターネットは2026年8月9日、同社が管理するサーバー環境で異常を検知し調査を開始した。その結果、第三者が同社の管理環境を経由して「さくらのレンタルサーバ」の一部顧客環境へ不正アクセスを行い、583アカウントへの不正ログインが判明した。攻撃者は一部サーバーにマルウェアを設置しており、顧客領域内に保存された情報や利用者識別子、さらには電気通信事業法上の「通信の秘密」に該当する情報へアクセス可能な状態であったことが確認された。8月17日に第一報、8月19日には続報として、販売管理システムへの不正アクセスの可能性が新たに判明し、対象となり得る会員情報が最大136万563アカウントに拡大する可能性があると公表された。同社は影響を受けた顧客への個別通知と、侵害範囲の継続調査を進めている。

**コラム**: レンタルサーバ事業者は多数の顧客企業のWebサイトやメールなどを預かるインフラ基盤であり、その侵害は一次被害企業のみならず、そこにサイトを持つ膨大な数の二次被害者に波及しうる、典型的なサプライチェーン型リスクである（ドメイン4）。583アカウントという当初の判明数から136万アカウントへと影響範囲が段階的に拡大した経緯は、インシデント初期の「影響範囲の過小評価」のリスクを示しており、フォレンジック調査の進展にあわせて開示情報を更新する透明性のある情報開示プロセス（ドメイン7）の重要性を教えてくれる。また「通信の秘密」に該当する情報への言及は、日本特有の電気通信事業法上の法的義務にも関わり、資産の機密区分（ドメイン2）を検討する際は業界固有の法規制も踏まえる必要があることを示す好例である。

## 用語解説

- **CVE（Common Vulnerabilities and Exposures）**: 個々の脆弱性に対して付与される共通識別子。「CVE-年-番号」の形式で表記され、業界横断で同一の脆弱性を参照する際の共通言語として使われる。
- **CVSS（Common Vulnerability Scoring System）**: 脆弱性の深刻度を0.0〜10.0の数値で評価する業界標準の指標。数値が高いほど悪用の容易さや影響の大きさが深刻であることを示す。
- **KEV（Known Exploited Vulnerabilities）カタログ**: 米CISAが管理する、実際に悪用が確認された脆弱性の一覧。連邦機関はKEV掲載の脆弱性を優先的に、期限付きで修正することが義務付けられている。
- **ゼロデイ（Zero-day）**: ベンダーが修正パッチを提供する前に、脆弱性が実際の攻撃に悪用されている状態、またはそのような脆弱性そのものを指す。
- **use-after-free（解放済みメモリの再利用）**: 一度解放（free）したメモリ領域に、プログラムが誤って引き続きアクセスしてしまうメモリ安全性の不具合。攻撃者に悪用されるとコード実行や権限昇格につながることがある。
- **レースコンディション（競合状態）**: 複数の処理が同じリソースに同時にアクセスする際、処理の順序次第で意図しない挙動やセキュリティ上の欠陥が生じる状態。
- **RCE（Remote Code Execution／リモートコード実行）**: ネットワーク経由で攻撃者が対象システム上に任意のコードを実行できてしまう、深刻度の高い脆弱性の種類。
- **Webシェル**: 侵害したWebサーバに設置される小型の不正プログラムで、攻撃者がブラウザ経由でコマンド実行やファイル操作などを行うための「裏口」として機能する。
- **JWT（JSON Web Token）**: ユーザーの認証情報や権限情報を安全にやり取りするためのトークン形式。署名検証や有効期限などの実装に不備があると、なりすましに悪用され得る。
- **認証バイパス**: 本来必要な認証手続きを経ずに、システムやリソースへのアクセス権を不正に取得してしまう攻撃・脆弱性の総称。
- **パストラバーサル（Path Traversal）**: ファイルパスの指定を細工することで、本来アクセスが許可されていないディレクトリやファイルに不正アクセスする攻撃手法。
- **PoC（Proof of Concept）**: 脆弱性が実際に悪用可能であることを示すための実証用コードやデモンストレーション。公開されると悪用の敷居が一気に下がる。
- **Living off the Land（環境寄生型攻撃）**: マルウェアを新たに持ち込まず、対象システムに元々存在する正規の管理ツールやコマンドを悪用して活動する攻撃手法。マルウェア検知製品でのみ防御することが難しい。
- **二重恐喝（Double Extortion）**: ランサムウェア攻撃において、システムの暗号化に加えて窃取したデータの公開もちらつかせ、二重に金銭を要求する恐喝手法。
- **RDP（Remote Desktop Protocol）**: Windowsのリモートデスクトップ接続に使われるプロトコル。攻撃者が侵害環境内で横展開（ラテラルムーブメント）する際にもしばしば悪用される。
- **横展開（ラテラルムーブメント）**: 攻撃者が最初に侵入した端末から、ネットワーク内の他の端末やシステムへと侵害範囲を広げていく活動。
- **多要素認証（MFA）**: パスワードなど単一の認証要素だけでなく、複数の異なる認証要素を組み合わせて本人確認を行う仕組み。不正アクセス対策の基本的な統制の一つ。
- **フォレンジック調査**: サイバーインシデント発生後に、ログやディスクイメージなどの電子的証拠を収集・分析し、侵入経路や被害範囲、攻撃者の手口を明らかにする調査手法。
- **通信の秘密**: 日本の電気通信事業法で保護される、通信内容や通信当事者に関する情報の秘密。通信事業者には厳格な保護義務が課される。
