## 1. Apache HTTP Server 2.4.71 公開：mod_http2 の未認証RCE（CVE-2026-119618、Red Hat評価 CVSS 9.8）

**概要**

## 2. 「wfx」GitHub Actions 認証情報スティーラー：乗っ取られた開発者アカウント経由で数千〜6万超のリポジトリに波及

**概要**
2026-11-12、Aikido Security の公表を受けて Endor Labs と SafeDep が、GitHub Actions の CI シークレットを大規模に窃取するキャンペーン「wfx」の分析を公開した。攻撃者は窃取済みトークンで開発者アカウントを乗っ取り、まず `wfx-docs` ブランチから「docs: dependency audit notes」という題のプルリクエストを出して書き込み権限を確認する。次に (a) 既存ワークフローへの注入（コミットメッセージ「ci: refresh build cache」）、(b) 新規ワークフロー追加（「chore: add dependency audit workflow」）、(c) npm の postinstall フック（「chore: add ci helper」、開発者端末の `npm install` でも実行）のいずれかでペイロードを仕込み、CI 上で実行後に「ci: restore」「ci: cleanup」で元に戻し、実行履歴とログを削除する（Endor Labs は「サンドイッチコミット」と呼称）。窃取対象は Actions の全シークレット・変数、GITHUB_TOKEN、OIDC トークン交換を経た AWS/Azure/GCP 認証情報、npm/PyPI/Packagist/crates のレジストリトークン、AI API キー、SSH/GPG 鍵、kubeconfig、Vault/Terraform 関連、`.env`・`*.tfvars`・`*.tfstate` など。さらに AWS ロール信頼ポリシーを `"AWS": "*"` に書き換える、IAM アクセスキーを新規作成する、Azure に `wfx-ci-*` という名前のフェデレーション資格情報を作る、といったバックドア設置も報告されている。規模は情報源で異なり、Endor Labs は「61,764 リポジトリが探査され、1,806 以上で認証情報が流出、開発者 4,837 人分の認証情報が窃取」、SafeDep は「悪意あるコミットを確認できたのは 8,093 リポジトリ（公開リポジトリの既定ブランチのみの下限値）」としている。最初の探査 PR は 11-10 12:45 UTC、webdriverio のボットアカウント侵害は 11-11 12:11 UTC。攻撃者名は不明。

## 3. CISA KEV に Cisco BroadWorks（CVE-2026-20320）・Openwave を追加：AIエージェントによる自律侵入「Operation Snowball」

**概要**
CISA は 2026-11-10 に6件の脆弱性を KEV カタログに追加した。うち報道で確認できたのは、Cisco BroadWorks の OCI（Open Client Interface）XML パーサにおける XXE 脆弱性 CVE-2026-20320（CVSS 7.5、未認証で細工した XML を OCI-P サービスに送ることで機微な設定情報を読み取れる）と、Openwave Media Transcoder の CVE-2026-111793（CVSS 4.3）である。Cisco は CVE-2026-20320 を 2026年8月に修正済み（アドバイザリ cisco-sa-bworks-xxe-uwUd7CEt）、Openwave の脆弱性は 10月に修正済みで、こちらは日本の JVN で注意喚起され、開発元が攻撃の観測を認めている。米連邦機関の対応期限は BOD 26-04 に基づき 2026-11-24。脅威インテリジェンス企業 Malbear Labs は、中国語話者とみられる正体不明の攻撃者が、ジェイルブレイクした DeepSeek Flash モデルを組み込んだエージェント型フレームワークで CVE-2026-20320 を悪用し、欧州の通信事業者と、そのデータセンターを利用する13組織を約2週間にわたり侵害したと報告した（「Operation Snowball」）。標的の BroadWorks XSP は Release 23.0.1.1075（ポート 2208）で、侵入後は Sliver、Chisel、Behinder Web シェルが使われ、XSP のシステム ID 秘密鍵、SSL 認証情報3組、その他の秘密鍵3本が窃取され、数百の資産が列挙され、加入者の課金・端末レコード数千行が持ち出されたという。AI 関与と被害規模は Malbear Labs の報告に依拠しており（単一情報源）、CISA 自身は悪用の詳細を公表していない。なお同日の KEV 追加には、前々日版で扱った Barracuda ESG の連鎖（CVE-2026-116606／CVE-2026-111560）も含まれると SecurityWeek が報じており、こちらは3日間の対応期限が設定されている。6件の全容は CISA のアラートページが取得できず未確認。

## 4. Xen Orchestra の認証バイパス（VSA-2026-062）が実際に悪用、XCP-ng ノードの root 奪取に至るおそれ

**概要**
仮想化基盤 XCP-ng／XenServer の管理ツール「Xen Orchestra」を開発する Vates は、重大な認証バイパスの脆弱性（アドバイザリ ID: VSA-2026-062、CVE 未採番、CVSS 未公表）が実環境で悪用されていると警告した（The Hacker News 11-10、SecurityWeek 11-11）。REST API のクッキーに `authenticationToken=j:%7B%7D` のような細工値を与えると空オブジェクトとして解釈され、トークン検索が「最初に見つかった有効期限内トークン」を返してしまうため、攻撃者はそのトークン所有者として認証される。管理者トークンに当たれば管理操作が可能となり、管理下のプールでのコード実行、XCP-ng ノードの root 奪取につながる。さらに `/rest/v0/users/me/authentication_tokens` から再利用可能なログイントークン ID を列挙できる。修正版は Xen Orchestra 6.9.1／6.10.0、xo-server 5.211.2／5.213.1。侵害指標として、cron ファイル `/etc/cron.d/zz-ustar`・`zz-ustar2`、`pivot2` という名前の VM、`hvm_serial: file` が設定された VM、通信先 91.211.251.112:8001（VirusTotal 上で RedLine Stealer の C2 と判定）などが挙げられている。悪用開始時期、被害組織数、攻撃者は公表されていない。発見者は TDC NET Security の研究者。

**関連CBKドメイン**: ドメイン3（セキュリティアーキテクチャとエンジニアリング）／ドメイン5（アイデンティティおよびアクセス管理）／ドメイン7（セキュリティ運用）

**コラム**
ハイパーバイザ管理プレーンの侵害は、その上で動く全ワークロードの機密性・完全性・可用性を一度に失わせるため、影響度は単一サーバの侵害とは桁が違う。今回の根本原因は「入力の型検証不足が認証判定を素通りさせた」という古典的な実装不備で、ドメイン8のセキュアコーディング（型の厳格な検証、フェイルセーフな既定動作）の教訓でもある。管理インターフェースをインターネットに直接公開せず、管理用ネットワークや VPN・踏み台経由に限定する構成であれば、こうした脆弱性の悪用可能性は大きく下がる。パッチ適用に加え、既存トークンの全失効と、提示された IoC（cron、不審 VM）による侵害調査を必ずセットで行いたい。

## 7. ScreenConnect を悪用するワーム型攻撃「SCKit」：MSP 経由で48組織・288端末以上に不正クライアント

**概要**
Huntress は、クラウドホスト型の ConnectWise ScreenConnect 管理パネルへのアクセスを得た攻撃者が、正規の「Run Command」機能を使って不正な ScreenConnect クライアントを管理対象端末にインストールし、「SCKit」と呼ばれるツールキットを配布していると報告した（The Hacker News 11-12、発展中の事案）。最初の検知は 2026-11-11 17:47 UTC 頃で、少なくとも48組織の288端末が影響を受けた。SCKit は永続化の設定、Microsoft Defender の除外設定の追加、「TrapWatch」というスケジュールタスクの作成を行い、技術者の端末から `.aspxauth` セッションクッキーを窃取して別のパネルへ拡散を試みるほか、Shared Toolbox 経由で SYSTEM 権限のペイロードを配信するなど、ワームのような挙動を示す。攻撃者は侵害した MSP に連番を付けており、これ以前にも他の MSP が侵害されていた可能性が示唆される。初期侵入経路は認証情報の侵害またはオペレーターセッションの乗っ取りとみられるが未確定で、Huntress は新たな製品脆弱性は確認していない。ConnectWise も製品脆弱性の証拠はないとしつつ、サードパーティ製拡張機能5種（Labtech Plus、RMM Plus、RMM+、RMM Plus Password Link、RMM+ Password Link）を、導入済みの約400のパートナー環境で無効化した。CVE はなく、攻撃者名は不明。公開された指標は IP アドレス 185.99.255.28 と 155.94.150.39。

**関連CBKドメイン**: ドメイン5（アイデンティティおよびアクセス管理）／ドメイン7（セキュリティ運用）／ドメイン1（セキュリティとリスクマネジメント）

**コラム**
RMM ツールは「正規の遠隔操作機能」そのものが攻撃手段になるため、脆弱性がなくても認証情報やセッションが奪われれば全顧客端末に到達される。前日版の N-able に続き MSP 基盤が標的となっており、委託先管理（サードパーティリスク）の観点で、自社に導入されている RMM エージェントの種類・接続先・権限を把握しているかが問われる。対策は、管理パネルへのフィッシング耐性 MFA、セッションクッキーの短寿命化と端末バインド、Run Command など高リスク機能の承認制、サードパーティ拡張の棚卸しである。利用側の組織は、未承認の ScreenConnect インスタンス ID を持つクライアントや Defender 除外設定の変更を EDR で検知できるようにしておきたい。

## 用語解説

- **CVE**: 公開された脆弱性に付与される世界共通の識別番号。
- **CVSS**: 脆弱性の深刻度を 0.0〜10.0 で数値化する共通評価基準。9.0 以上が「Critical（緊急）」。
- **CWE**: 脆弱性の「種類」を分類する共通の一覧。CWE-346 はオリジン検証エラー。
- **EPSS**: ある脆弱性が今後30日以内に悪用される確率を推定する指標。
- **KEV（Known Exploited Vulnerabilities）**: 米 CISA が管理する「実際に悪用が確認された脆弱性」のカタログ。
- **BOD 26-04**: 米連邦機関に KEV 掲載脆弱性の期限内修正を義務付ける CISA の拘束的運用指令。
- **CISA**: 米国サイバーセキュリティ・インフラストラクチャセキュリティ庁。
- **CERT-EU**: EU 機関向けのコンピュータ緊急対応チーム。
- **JPCERT/CC**: 日本国内のインシデント対応調整や注意喚起を行う組織。
- **JVN**: JPCERT/CC と IPA が共同運営する脆弱性対策情報ポータル。
- **IPA**: 情報処理推進機構。国内向けに重要なセキュリティ情報を発信する。
- **PSIRT**: 製品ベンダー内で自社製品の脆弱性対応を担うチーム。
- **RCE（リモートコード実行）**: 攻撃者が遠隔から対象システム上で任意のプログラムを実行できる状態。
- **ヒープ破壊**: プログラムが動的に確保したメモリ領域を不正に書き換えてしまう不具合。コード実行に悪用され得る。
- **Use-After-Free**: 解放済みのメモリを再び使ってしまう不具合。情報漏えいやコード実行につながる。
- **NULL ポインタ参照**: 無効なメモリ番地を参照してプロセスが異常終了する不具合。主にサービス停止（DoS）の原因となる。
- **HTTP/2／mod_http2**: 通信を多重化して高速化する HTTP の新しい版と、Apache でそれを実装するモジュール。
- **XXE（XML 外部実体参照）**: XML の外部実体機能を悪用し、サーバ内のファイル読み取り等を行う攻撃。
- **OCI／OCI-P**: Cisco BroadWorks のプロビジョニング用 XML インターフェース。
- **認証バイパス**: 正規の認証手続きを経ずにログイン済みとして扱われてしまう脆弱性。
- **認可バイパス**: 認証後、本来許可されていない操作やデータにアクセスできてしまう脆弱性。
- **権限昇格**: 低い権限から管理者・root・SYSTEM などの高い権限を不正に得ること。
- **オリジン検証エラー／CORS**: リクエストの発信元（オリジン）の確認不備。CORS はブラウザが別オリジンへのアクセスを制御する仕組み。
- **SSRF**: サーバに意図しない宛先へリクエストを送らせる攻撃。
- **サプライチェーン攻撃**: 開発ツール・依存パッケージ・委託先など、供給網の一部を侵害して最終標的に到達する攻撃。
- **CI/CD**: ソフトウェアのビルド・テスト・配備を自動化する仕組み。
- **GitHub Actions／ワークフロー**: GitHub が提供する CI/CD 機能と、その処理を定義するファイル。
- **GITHUB_TOKEN**: ワークフロー実行時に自動発行される、リポジトリ操作用の一時トークン。
- **OIDC（トークン交換）**: 長期の鍵を置かずに、CI が短期のクラウド認証情報を取得するための認証連携方式。
- **フェデレーション資格情報**: 外部の ID 提供元を信頼してクラウドへのアクセスを許可する設定。
- **IAM／信頼ポリシー**: クラウドの権限管理の仕組みと、「誰がそのロールを引き受けられるか」を定める設定。
- **postinstall フック**: npm パッケージのインストール直後に自動実行されるスクリプト。
- **CODEOWNERS**: 特定ファイルの変更に指定担当者のレビューを必須にする GitHub の機能。
- **SBOM**: ソフトウェアに含まれる部品（依存ライブラリ等）の一覧表。
- **IoC／IOC（侵害指標）**: 侵害の痕跡を示す IP アドレス、ファイル名、ハッシュ値など。
- **C2（Command and Control）**: 攻撃者が侵害端末を遠隔操作するための通信基盤。
- **Web シェル**: Web サーバ上に置かれ、ブラウザ経由でコマンド実行を可能にする不正プログラム（例: Behinder）。
- **Sliver／Chisel**: それぞれ侵入後の遠隔操作フレームワーク、通信トンネリングツール。攻撃者にも悪用される。
- **RedLine Stealer**: 認証情報などを窃取する情報窃取型マルウェア。
- **ジェイルブレイク（AI）**: AI モデルの安全上の制限を回避して、本来拒否される動作をさせること。
- **エージェント型 AI**: 目標に向けて複数の手順を自律的に計画・実行する AI システム。
- **ハイパーバイザ／XCP-ng**: 仮想マシンを動かす基盤ソフトウェアと、その一種であるオープンソース製品。
- **cron／systemd**: Linux で処理を定期実行・常駐実行させる仕組み。攻撃者の永続化にも悪用される。
- **永続化**: 再起動や修正後も攻撃者がアクセスを維持できるようにする仕掛け。
- **FGFM**: FortiGate と FortiManager 間の管理用プロトコル。
- **OSPF**: ルータ同士が経路情報を交換する動的ルーティングプロトコル。
- **RADIUS**: ネットワーク機器の認証・認可・課金を集中管理するプロトコル。
- **TLS／mTLS**: 通信を暗号化するプロトコルと、クライアント側も証明書で認証する相互認証方式。
- **SNI**: TLS 接続時に接続先ホスト名を伝える拡張。
- **再ネゴシエーション**: 確立済みの TLS 接続の中で鍵や認証を取り直す TLS 1.2 以前の機能。
- **フェイルオープン**: 異常時に「許可」側へ倒れてしまう動作。安全側（拒否）に倒すフェイルセーフの対義。
- **QUIC**: UDP 上で動作する新しいトランスポートプロトコル。HTTP/3 の基盤。
- **RMM**: 端末を遠隔から監視・管理するツール。MSP が顧客環境の運用に用いる。
- **MSP**: 顧客の IT 運用を請け負うマネージドサービス事業者。
- **セッションクッキー（.aspxauth）**: ログイン済み状態を示すクッキー。窃取されるとパスワードなしでなりすまされる。
- **EDR**: 端末上の不審な挙動を検知・対応するセキュリティ製品。
- **SOAR**: セキュリティ運用の対応手順を自動化・連携する仕組み。
- **MFA／パスキー**: 複数要素による認証と、フィッシングに強いパスワードレス認証方式。
- **リスト型攻撃**: 他サービスから流出した ID・パスワードの組を使ってログインを試みる攻撃。
- **ランサムウェア**: データを暗号化または窃取し、身代金を要求するマルウェア・攻撃手法。
- **リークサイト**: ランサムウェア集団が被害組織名や窃取データを公開する Web サイト。
- **ゼロデイ**: 修正が提供される前に悪用される脆弱性。
- **PoC（概念実証）**: 脆弱性が実際に悪用できることを示すコードや手順。
- **トークン化**: カード番号などを意味のない代替値に置き換えて保持する保護手法。
- **PCI DSS**: クレジットカード情報を扱う事業者向けの国際的なセキュリティ基準。
- **サードパーティリスク**: 委託先や取引先のセキュリティ事故が自組織に及ぼすリスク。
