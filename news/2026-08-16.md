## 1. Windowsカーネルドライバのゼロデイ（CVE-2026-68820）を北朝鮮系Lazarusが悪用

**概要**: MicrosoftはAFD.sys（Windows Ancillary Function Driver for WinSock）に存在するUse-After-Free（解放済みメモリ使用）の脆弱性CVE-2026-68820を2026年8月11日のPatch Tuesdayで修正した。CVSSスコアは7.0（Important）で、複数スレッドがソケット関連の状態を同時に操作する際の同期不備が原因とされる。ローカルで既に足場（コード実行権限）を得ている攻撃者がこの脆弱性を悪用すると、追加のユーザー操作なしにSYSTEM権限へ昇格できる。Check Point Researchは2026年7月28日にMicrosoft Security Response Centerへ報告し、Microsoftは7月31日に問題を確認、8月5日にCVE番号を割り当て、8月11日に修正パッチを公開した。北朝鮮系脅威グループLazarus（Operation Dream Job作戦の一環）は7月上旬から本脆弱性を悪用し、防衛関連企業を標的に、同グループ特有のカーネルモード・ルートキット「FudModule」を展開していたことがCheck Pointにより確認されている。CISAはKnown Exploited Vulnerabilities（KEV）カタログに追加し、連邦機関に2週間以内のパッチ適用を義務付けた。

**関連CBKドメイン**: ドメイン3（セキュリティアーキテクチャとエンジニアリング）／ドメイン7（セキュリティ運用）

**コラム**: Use-After-Freeはメモリ管理の欠陥に起因する典型的な脆弱性クラスであり、セキュアコーディングおよびカーネルレベルの防御機構（メモリ安全言語、カーネルドライバの入力検証）の重要性を再認識させる事例である。加えて本件は「権限昇格の悪用には事前の初期侵入が必要」という点で、多層防御（Defense in Depth）とEDR（Endpoint Detection and Response）による早期検知の価値を示している。国家関与の脅威アクターが防衛産業を狙う構図は、資産の重要度に応じたリスクベースのパッチ適用優先順位付け（Risk-Based Vulnerability Management）を実務者に求めるものである。

## 2. SonicWall SMA1000のゼロデイ2件をINCランサムウェアが連鎖悪用しVPN機器を乗っ取り

**概要**: SonicWallのSSL-VPNアプライアンスSMA1000シリーズに、CVSSスコア10.0（最高値）のCVE-2026-15409（事前認証SSRF）と、CVSSスコア7.2のCVE-2026-15410（コマンド実行）という2件の脆弱性が発見された。攻撃者は未認証のまま/wsproxyエンドポイントを悪用し、任意の宛先ホスト・ポートを指定できる仕様を利用してループバック限定サービス（ポート1050で稼働するErlangランタイム）にWebSocketトンネルを開通させ、初期コード実行を獲得する（CVE-2026-15409）。これを足掛かりにCVE-2026-15410を連鎖させることでアプライアンス上でのコマンド実行・root権限奪取に至る。2026年8月初旬からランサムウェアグループ「INC Ransomware」がこの攻撃チェーンの悪用を加速させており、データリークサイトには米国・オーストラリア・UAE・コロンビア・スイスなど複数国の被害組織が新たに掲載されている。侵入後は高価値な認証情報、アクティブセッションデータベース、TOTP多要素認証のシード設定を窃取し、長期的な永続アクセスと内部ネットワークへの横展開（ラテラルムーブメント）を狙う手口が確認されている。

**関連CBKドメイン**: ドメイン4（通信とネットワークセキュリティ）／ドメイン5（アイデンティティおよびアクセス管理）／ドメイン7（セキュリティ運用）

**コラム**: VPNゲートウェイのような境界防御装置は「信頼された内側」への唯一の入口であるため、そこでの認証バイパス（SSRF起点）は組織全体の信頼モデルを崩壊させる。特にTOTPのMFAシードそのものが窃取された点は、MFA導入だけでは十分でなく、シークレットの保管・ローテーション設計まで含めたIAM統制が必要であることを示す。境界機器のパッチ適用サイクルの短縮と、侵害後のMFAシード無効化・再発行を組み込んだインシデント対応計画（IRP）の見直しが実務上の教訓となる。

## 3. GeoServerの未パッチSQLインジェクション（RCEに悪用可能）が公開直後から実悪用

**概要**: オープンソースの地理空間データサーバー「GeoServer」において、JSON配列フィールドの値を検索するフィルタ式`jsonArrayContains`関数に未認証のSQLインジェクション脆弱性が存在することが、2026年8月12日10:46(UTC)にセキュリティ研究者@q1uf3ng氏によりX（旧Twitter）上で公表された。本脆弱性はH2データベースを利用する一部の構成においてリモートコード実行（RCE）に発展しうる。開発チームによれば、これは2023年2月に修正済みの重大な脆弱性CVE-2023-25158（CVSS 9.8）の「リグレッション（再発）」であるとされ、過去の修正が不完全であった可能性を示唆する。公開からわずか数時間で、少数のIPアドレス群から数百件規模の実悪用の試みが観測されており、記事執筆時点で正式なCVE番号の割り当ておよび恒久的な修正パッチは未提供の状態が続いている。CISAも本脆弱性に関する注意喚起を発出した。

**関連CBKドメイン**: ドメイン8（ソフトウェア開発セキュリティ）／ドメイン6（セキュリティの評価とテスト）

**コラム**: 過去に修正されたはずの脆弱性が形を変えて再発する「リグレッション」は、パッチそのものの妥当性検証（回帰テスト・セキュリティ回帰テスト）がSDLC（Software Development Lifecycle）に組み込まれていない場合に典型的に起こる。入力値の無害化（サニタイズ）がコードベースの一部にしか適用されていなかった可能性もあり、静的解析（SAST）やコードレビューの網羅性を定期的に監査する重要性を物語る。ゼロデイかつパッチ未提供という状況下では、WAF（Web Application Firewall）によるシグネチャベースの緩和策や、当該機能の一時無効化といった補完的統制（Compensating Control）の適用判断がCISSP実務者に求められる。

## 4. 中国系脅威アクターStorm-1175、N-able N-centralの認証バイパスを悪用し新型ランサムウェア「StormEncryptor」を展開

**概要**: Microsoft Threat Intelligenceは、金銭目的で中国関連とされる脅威アクター「Storm-1175」が、これまで使用していたMedusaランサムウェアから、C++で書かれた新種のランサムウェア「StormEncryptor」に手法を切り替えたと公表した。初期侵入経路としては、法人向けリモート監視・管理（RMM）ツール「N-able N-central」の認証バイパス脆弱性CVE-2026-18577が悪用された可能性が高いとされる。この脆弱性は、2026年に修正済みだった別の脆弱性CVE-2026-18556に対するパッチの検証ロジックを回避する「パッチバイパス」であり、N-ableは8月10日までに2度目のホットフィックスを提供したが攻撃は継続していた。侵害後、Storm-1175はAnyDeskやSimpleHelpといった正規のRMMツールを悪用してアクセスを維持し、Advanced IP Scannerで内部探索を行い、Mimikatzを用いてLSASSプロセスから認証情報をダンプするなど、初期侵入からデータ窃取・ランサムウェア展開までを数日以内に完了させる高速な攻撃サイクルが観測されている。StormEncryptorは暗号化したファイルに`.encrypted`拡張子を付与し、各ディレクトリに`!!!README_FIRST!!!.txt`という名前の脅迫文を設置する。

**関連CBKドメイン**: ドメイン1（セキュリティとリスクマネジメント）／ドメイン5（アイデンティティおよびアクセス管理）／ドメイン7（セキュリティ運用）

**コラム**: MSP（マネージドサービスプロバイダー）が利用するRMMツール自体が攻撃対象となり、正規の管理ツールが横展開や永続化に悪用される「Living off the Land」型の手口は、サードパーティ／サプライチェーンリスク管理（ドメイン1）の重要性を端的に示す。特に「パッチ済みのはずの脆弱性のバイパス」という構図は、脆弱性管理を一度の修正で終わらせず、修正の有効性そのものを継続的に検証する運用体制の必要性を浮き彫りにする。MSP経由の侵害は多数の顧客組織に波及するため、委託先管理（サードパーティリスクアセスメント）と契約上のセキュリティ要件の明文化が実務上の対策となる。

## 5. Clopランサムウェア集団、金融テクノロジー大手FIS Global（Fiserv）から約874GBのデータ窃取を主張

**概要**: 2026年8月5日、ランサムウェア／データ恐喝グループ「Clop」が金融テクノロジー大手FIS Global（Fiserv）への攻撃を主張し、自らのリークサイト上でプロジェクトファイル、CADファイル、PLM（製品ライフサイクル管理）ツールWindchill関連データなど約874GBのデータを窃取したと表明した。身代金交渉が不調に終わった場合、データを公開すると脅迫している。FIS Globalは世界中の数千の金融機関に決済・銀行・金融テクノロジー基盤を提供する企業であり、本件が事実であれば金融セクター全体へのサプライチェーン的波及リスクが懸念される。ただし、874GBという規模や窃取範囲は現時点で脅威アクター側の主張にとどまり、被害organizationや第三者による独立した検証は確認されていない（単一情報源であることに留意が必要）。ClopはMOVEit Transferなどファイル転送ソフトの脆弱性を悪用した大規模データ恐喝キャンペーンで知られる集団である。

## 6. 名鉄協商（日本）へのランサムウェア攻撃、委託先経由で約4,000件の顧客情報が流出の可能性

**概要**: 名古屋鉄道グループで駐車場・カーシェア事業（「名鉄協商パーキング」「カリテコ」等）を展開する名鉄協商株式会社は、2026年6月19日にランサムウェアによる不正アクセスの痕跡を確認し、6月23日午前8時ごろにサーバへの不審なアクセスを検知して一部サーバを緊急停止した。この影響で駐車場サービス、MKPポイントカード、月ぎめ駐車場、カーシェアサービス「カリテコ」など複数のWebサービスで機能停止・遅延が発生し、7月末時点でも完全復旧の見通しが立っていない状態が続いていた。その後の調査で複数サーバーへの攻撃が確認され、同社が駐車場管理業務を委託していた中電不動産が管理する月極駐車場契約者のうち、2018年〜2024年分の顧客情報約4,000件が外部に流出した可能性があることが明らかになった。名鉄協商自体の直接保有データについては、本稿執筆時点で具体的な漏洩の事実は確認されていないとされる。

## 7. Microsoft 2026年8月Patch Tuesday：421件のCVEを修正、クリティカル脆弱性が多数

**概要**: Microsoftは2026年8月11日、月例セキュリティ更新（Patch Tuesday）として421件の脆弱性を修正するパッチをリリースした。悪用が確認済みのゼロデイが1件（前述のCVE-2026-68820）、公開済みだが悪用未確認のゼロデイが3件、Critical評価が62件含まれる。悪用手法別ではElevation of Privilege（権限昇格）が174件（42%）、Remote Code Execution（リモートコード実行）が109件（26%）、情報漏洩が85件（20%）を占めた。特に注目すべきは、Microsoft QUICプロトコル実装に存在するUse-After-Free脆弱性CVE-2026-62815（CVSSスコア9.8）で、未認証のリモート攻撃者がユーザー操作なしに低い攻撃複雑度でコード実行が可能とされる。また、Windows Deployment Services TFTPサーバーのリモートコード実行脆弱性CVE-2026-62893（CVSS 9.8）、Windows DHCPサーバーの脆弱性CVE-2026-62823（CVSS 8.8）についても、Microsoftは「悪用の可能性が高い（Exploitation More Likely）」と評価している。日本国内でもIPA（情報処理推進機構）が8月12日付でMicrosoft製品脆弱性対策情報を公表し、特にCVE-2026-68820については悪用の事実が確認済みであるとして至急のパッチ適用を呼びかけている。

**関連CBKドメイン**: ドメイン3（セキュリティアーキテクチャとエンジニアリング）／ドメイン6（セキュリティの評価とテスト）

**コラム**: 単月で400件を超える脆弱性が公開される状況は、すべてを即座に修正することが現実的に不可能であることを意味し、CVSSスコアだけでなく「悪用可能性（Exploitation Likelihood）」「資産の重要度」「外部からの到達可能性」を組み合わせたリスクベースの優先順位付け（例：CISAのKEVカタログやEPSSスコアの活用）が不可欠である。QUICやDHCP、TFTPといったネットワークプロトコル実装の脆弱性は、パッチ適用前の暫定策としてネットワークセグメンテーションや不要サービスの無効化といった補完的統制の検討価値を示す。パッチマネジメントプロセスの成熟度（検知・評価・適用・検証のサイクル）そのものが、組織のセキュリティ運用能力を測る重要な指標となる。

## 用語解説

- **CVE（Common Vulnerabilities and Exposures）**: 公開された個々の脆弱性に一意の識別番号を付与する国際的な採番制度。「CVE-2026-XXXXX」のように西暦と通番で構成され、脆弱性情報の共有・追跡を容易にする。
- **CVSS（Common Vulnerability Scoring System）**: 脆弱性の深刻度を0.0〜10.0の数値で表す業界標準の評価指標。スコアが高いほど悪用の容易さや影響が大きいことを示す。
- **ゼロデイ（Zero-Day）**: ベンダーが修正パッチを提供する前に、脆弱性の存在が悪用されてしまう状態、またはその脆弱性自体を指す。防御側の対応が「0日」しかない状況からこう呼ばれる。
- **RCE（Remote Code Execution／リモートコード実行）**: 攻撃者がネットワーク越しに標的システム上で任意のコードを実行できてしまう脆弱性の分類。深刻度が非常に高いとされることが多い。
- **SQLインジェクション**: アプリケーションがユーザー入力を適切に検証・無害化せずにSQL文へ組み込んでしまうことで、攻撃者が意図しないデータベース操作を実行できてしまう脆弱性。
- **SSRF（Server-Side Request Forgery）**: サーバー側の機能を悪用し、攻撃者が本来アクセスできないはずの内部ネットワークやローカルサービスへリクエストを送らせる攻撃手法。
- **Use-After-Free（解放済みメモリ使用）**: 一度解放（free）したメモリ領域に対して、プログラムが誤って引き続きアクセスしてしまうメモリ管理上の欠陥。攻撃者に悪用されるとコード実行や権限昇格につながることがある。
- **権限昇格（Privilege Escalation / Elevation of Privilege）**: 攻撃者が本来割り当てられている権限よりも高い権限（管理者権限やSYSTEM権限など）を不正に取得する行為。
- **MFA（Multi-Factor Authentication／多要素認証）**: パスワードに加え、ワンタイムコードや生体情報など複数の要素を組み合わせて本人確認を行う認証方式。
- **TOTP（Time-based One-Time Password）**: 時刻情報を基に一定間隔で自動更新されるワンタイムパスワードを生成する仕組み。多要素認証でよく利用される。
- **ラテラルムーブメント（Lateral Movement／横方向移動）**: 攻撃者が初期侵入した端末を足掛かりに、組織内の他のシステムへ侵害範囲を広げていく攻撃段階。
- **RMM（Remote Monitoring and Management）ツール**: IT管理者やMSPが遠隔から複数の端末・サーバーを監視・管理するために使うソフトウェア。攻撃者に悪用されると正規ツールを隠れ蓑にした侵害活動（Living off the Land）に利用されることがある。
- **KEVカタログ（Known Exploited Vulnerabilities Catalog）**: 米国CISAが公開する、実際に悪用が確認された脆弱性の一覧。連邦機関には掲載脆弱性の優先的なパッチ適用が義務付けられている。
- **サプライチェーンリスク**: 自社が直接管理していない委託先・取引先・ソフトウェアベンダーなど、供給網を構成する第三者に起因して発生するセキュリティリスク。
- **パッチマネジメント**: 脆弱性修正プログラム（パッチ）の検知・評価・適用・検証を体系的に運用するプロセス。組織のリスク低減において最も基本的かつ重要な統制の一つ。
- **データ恐喝（Data Extortion）**: データを暗号化せず窃取のみを行い、公開すると脅して金銭を要求する手口。近年は暗号化を伴わない「恐喝特化型」のランサムウェア集団も増えている。
- **EDR（Endpoint Detection and Response）**: エンドポイント（PCやサーバー）上の挙動を継続的に監視し、不審な活動を検知・対応するセキュリティ製品・仕組み。
- **BCP（Business Continuity Plan／事業継続計画）**: 災害やサイバー攻撃などの重大インシデント発生時にも、重要業務を継続または早期に復旧させるための計画。
