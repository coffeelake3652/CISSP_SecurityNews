## 2. Linux カーネル IPv4 TCP の use-after-free（CVE-2026-98432, CVSS 9.8）— MPTCPリスナー環境で未認証rootの実証、RHELは修正パッケージ未提供

**概要**
Linuxカーネルの IPv4 TCP 処理における use-after-free（IPv4オプション領域 `ireq_opt`/`inet_opt` の解放競合）で、SYN再送時にSYN-ACKを構築するCPUと子ソケット破棄が競合すると、解放済みメモリが参照される。原因は`inet_sock_destruct()`等でRCU対応の解放（`kfree_rcu()`）が必要な箇所に通常の`kfree()`が使われていたことで、競合は2015年のコミットに遡り、Linux 4.4以降が影響を受ける。修正はEric Dumazet氏による2行の変更。CVEは10月15日に公開、10月27日にAnthropicのFrontier Red Teamが「MPTCPリスナーを持つサーバで未認証のリモートroot」を実証する研究を公開した（PoCではKASLR回避に48分、制御奪取に約5分）。10月29日にGoチームが勧告を出しMPTCPのデフォルト無効化を提案、Red Hatは深刻度を引き上げ「Critical」とした（The Hacker News, 11/3）。CVSSはカーネルCNAが9.8、Red Hatのドラフトは8.1。修正済みカーネルは5.10.272 / 5.15.223 / 6.1.190 / 6.6.159 / 6.12.113 / 6.18.56 / 7.2.10 / 7.3。10/30時点でDebian 12/13は修正済み、RHEL 8/9/10・OpenShift 4は影響ありで修正パッケージ未掲載、Ubuntuは未確認（RHEL 6/7は影響なし）。回避策は`net.mptcp.enabled=0`やGoの`GODEBUG=multipathtcp=0`だが、これは実証された前提条件を外すだけでバグ自体はMPTCP固有ではないため、非MPTCP環境も露出し得る。公開エクスプロイトコードの存在は確認できていない。

**コラム**
10年以上潜伏した競合状態が、AIを用いた研究によって「CVE公開後わずか12日」で実用的なリモートroot手順に変換された。パッチ適用SLAの前提（公開から悪用まで数週間）が崩れつつある点が示唆である（ドメイン7：パッチ・脆弱性管理）。MPTCP無効化などのコンパニオン緩和策は、使用していない機能を削る「攻撃対象領域の縮小」というドメイン3の原則に沿うが、根本修正の代替ではない。ディストリビューションごとの修正状況の差（RHELは未提供）も、資産台帳とカーネルバージョン管理を持つことの重要性を示す。

**概要**
PHPプロジェクトは2026年10月20日に事前予告を出し、10月21日14:00 UTCに、未認証のリモートコード実行につながる2件の脆弱性（いずれもCVSS v4.0 9.2）を公表した。CVE-2026-109618はメモリ不足処理時にリクエストデータが部分的に未初期化のまま残る問題、CVE-2026-109619は解放後のリクエスト所有の状態が同一ワーカー上の後続リクエストで再利用される問題である。修正版はPHP 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35（8.2は2026年12月31日にEOL）。php.netは緩和策は露出を減らすのみで、更新が唯一の完全な対策としている。10/23にはセッションアップロード進捗に関する情報アドバイザリ（CVE-2026-115560、次回リリースで正式公表予定。`session.upload_progress.enabled=0`を推奨）、10/26にはWindows版PHPのBrotli 1.2.1更新（CVE-2026-111497, 境界外書き込み）が追加された。CERT-EUは10/23に勧告（2026-018）を、JPCERT/CCは10/29に注意喚起を更新している。ScanNetSecurity（11/4）は、j.union社が脆弱性対応のためサービスを停止していた「くみあいアプリ」について、停止が2か月以上に及ぶとして再開を断念し、10/30にサービス終了を発表したと報じた。同記事からは脆弱性の悪用有無や情報流出の有無は確認できない。PHP 8.6.0のRC5は11/5に予定されている。

**コラム**
広く使われる言語ランタイムの重大脆弱性は、パッチ適用が難しい環境（レガシーなホスティング、サポート切れバージョン）ほどビジネス継続性への影響が大きく、今回のようにサービス終了という判断に至るケースもある。ドメイン1では、ランタイムのEOL管理とBIAに基づく復旧時間の見積り、ドメイン8ではSDLC内の依存関係・ランタイム更新計画が問われる。ドメイン7では、事前予告型アドバイザリを受けた緊急パッチ体制（予告から公開までの準備）の有効性を検証する材料となる。

## 用語解説

- **CBK（Common Body of Knowledge）**: CISSPの試験範囲となる8つのドメインからなる知識体系。
- **CVE**: 脆弱性に付与される共通の識別番号。
- **CVSS**: 脆弱性の深刻度を0〜10で表す評価指標。9.0以上が「緊急」とされる。
- **ゼロデイ**: 修正パッチが提供される前に悪用される脆弱性。
- **RCE（リモートコード実行）**: ネットワーク越しに攻撃者が任意のコードを実行できる脆弱性。
- **use-after-free（UAF）**: 解放済みのメモリを再度使ってしまうバグで、コード実行につながり得る。
- **KASLR**: カーネルのメモリ配置をランダム化して攻撃を難しくする防御機構。
- **RCU / kfree_rcu()**: Linuxカーネルの同期方式。他CPUが参照中のメモリを安全に解放するための仕組み。
- **MPTCP（Multipath TCP）**: 複数の経路を同時に使うTCPの拡張。
- **SYN / SYN-ACK**: TCP接続確立時（3ウェイハンドシェイク）に交換されるパケット。
- **SQLインジェクション**: 入力値を通じてデータベースへの命令を不正に差し込む攻撃。
- **REST API**: HTTPでデータをやり取りするWebサービスの標準的なインターフェース。
- **PoC（概念実証）**: 脆弱性が実際に悪用できることを示すコード。
- **サプライチェーン攻撃**: 取引先・ソフトウェア配布経路など、供給網の弱い部分から侵入する攻撃。
- **トロイ化（トロイの木馬化）**: 正規ソフトに見せかけて悪意のあるコードを仕込むこと。
- **C2（コマンド&コントロール）サーバ**: マルウェアに指令を出す攻撃者側のサーバ。
- **TraderTraitor**: 北朝鮮系とされる、暗号資産企業を狙う攻撃グループ。
- **Tornado Cash**: 暗号資産の取引履歴を追跡しにくくするミキシングサービス。
- **ウォレット署名サービス**: 暗号資産の送金に必要な電子署名を行う内部システム。
- **権限トークン**: システムへのアクセス権を証明する認証用の文字列。流出すると不正利用される。
- **KASLR回避 / 特権昇格（root）**: 一般権限から管理者最高権限を得ること。
- **OT / IoT**: 工場・設備などの制御系技術（OT）と、ネットワークにつながる機器（IoT）。
- **EOL（サポート終了）**: ベンダーが更新やサポートを終了した状態。脆弱性が修正されない。
- **ASM（攻撃対象領域管理）**: インターネットから見える自社資産を継続的に把握・管理する取り組み。
- **デフォルトパスワード**: 出荷時の初期設定のままのパスワード。攻撃者に推測されやすい。
- **VPN**: 暗号化された安全な通信路をインターネット上に作る技術。
- **コード署名**: ソフトウェアが改ざんされていないことを電子署名で保証する仕組み。
- **IoC（侵害指標）**: 侵害の痕跡を示すファイル名・IPアドレス等の情報。
- **ファームウェア**: 機器に組み込まれた制御用ソフトウェア。
- **コマンドインジェクション**: 入力を悪用して、OSの命令を不正に実行させる攻撃。
- **WAF（Webアプリケーションファイアウォール）**: Webアプリへの攻撃を検知・遮断する装置/サービス。
- **EOL管理 / BIA（事業影響度分析）**: 業務停止による影響を評価し、復旧優先度を決める手法。
- **SDLC**: ソフトウェア開発のライフサイクル全体。
- **ランサムウェア**: データを暗号化し、復旧と引き換えに身代金を要求するマルウェア。
- **ダークウェブ**: 通常の検索では到達できず、不正取引の場にもなる匿名性の高いネットワーク領域。
- **LLMjacking**: 盗んだLLMのAPIキーを使い、他人のアカウントでAIサービスを大量利用する不正行為。
- **パスキー**: パスワードを使わず、端末の生体認証等で認証する仕組み。
- **2FA（二要素認証）**: パスワードに加え、もう一つの要素で本人確認する方式。
- **ボットネット**: 乗っ取られた多数の機器をまとめて遠隔操作するネットワーク。
- **KEV（Known Exploited Vulnerabilities）**: CISAが管理する「悪用が確認された脆弱性」のカタログ。
