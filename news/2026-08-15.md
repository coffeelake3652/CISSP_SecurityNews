## 1. VMware vCenter の重大脆弱性（CVE-2026-59310）、公表5日後から世界的悪用

**概要**: Broadcomは7月29日、VMware vCenterのSyslogサーバーに存在するディレクトリトラバーサル脆弱性CVE-2026-59310（CVSS 9.8）を含む複数の脆弱性を修正するパッチを公開した。しかし公表からわずか5日後の8月3日、高度な攻撃者（APTとみられる)がこの脆弱性の悪用を開始したことが観測されている。攻撃はパストラバーサルによる侵入後、オープンソースツール「reverse_ssh」を利用した不正cronジョブを設置し、攻撃者インフラへの持続的なリバースSSH接続を確立する手口が確認された。セキュリティ企業の調査では、47カ国にまたがる361件の被害IPアドレスが観測されており、ドイツ・米国・トルコ・イラン・フランスの上位5カ国だけで185件を占める。CVSS 9.8は「ネットワーク経由・低複雑性・権限不要」で任意コード実行が可能なことを示しており、仮想化基盤の中枢を握られるリスクが極めて高い。

**関連CBKドメイン**: ドメイン3（セキュリティアーキテクチャとエンジニアリング）／ドメイン7（セキュリティ運用）

**コラム**: 仮想化管理基盤（vCenter）は多数のワークロードを一元管理する要であり、侵害されると管理下の全仮想マシンに影響が及びうる。パッチ公開から悪用開始までわずか5日という速さは、パッチ管理のSLA（重大脆弱性は数日以内に適用）を再考する材料になる。CISSP実務者は、パッチ適用の迅速化に加え、Syslogサーバーなど管理系コンポーネントのネットワーク露出を最小化する多層防御（セグメンテーション、管理インターフェースの外部非公開化）を徹底すべきである。またcronジョブの改ざん検知など、侵入後の永続化を検知するホスト型監視の重要性も再確認できる事例である。

**参照**: [SecurityWeek](https://www.securityweek.com/critical-vmware-vcenter-vulnerability-in-attackers-crosshairs/) / [The Hacker News](https://thehackernews.com/2026/08/attackers-exploit-vmware-vcenter.html) / [BleepingComputer](https://www.bleepingcomputer.com/news/security/critical-vmware-vcenter-rce-flaw-exploited-for-reverse-ssh-access/amp/)

## 2. Lazarus Groupが悪用したWindowsカーネル権限昇格ゼロデイ（CVE-2026-68820）

**概要**: マイクロソフトは8月11日（8月度Patch Tuesday）、Windows Ancillary Function Driver for WinSock（AFD.sys）に存在する権限昇格の脆弱性CVE-2026-68820を修正した。CVSSスコアは7.0で、複数スレッドがソケット関連の状態に同時アクセスする際の同期不備によるUse-After-Free（解放済みメモリの再利用）が原因。攻撃者が既にローカルで実行可能なコードを持つ場合、特別に細工したアプリケーションでレースコンディションを繰り返し発生させ、SYSTEM権限への昇格が可能となる。報道によれば、北朝鮮の関与が指摘されるLazarus Groupが、防衛・航空宇宙・航空関連組織を標的に、この脆弱性を約5週間にわたりゼロデイとして悪用していたとされる。マイクロソフトは今回のPatch Tuesdayで421件の脆弱性（うちCritical 62件）を修正しており、本脆弱性はその中で「悪用確認済み」の1件として扱われている。

**関連CBKドメイン**: ドメイン6（セキュリティの評価とテスト）／ドメイン7（セキュリティ運用）

**コラム**: 権限昇格の脆弱性は単体では侵入経路にならないが、フィッシング等で初期アクセスを得た攻撃者にとって「SYSTEM権限」への昇格手段として極めて価値が高い。国家支援型攻撃グループが約5週間にわたり気づかれずに悪用していた事実は、EDR等のホスト型検知だけに頼らず、異常なプロセス挙動やレースコンディションを悪用する挙動パターンの検知（ビヘイビア分析）の必要性を示す。特に防衛・航空宇宙セクターは標的型攻撃の主要ターゲットであり、脆弱性評価（ドメイン6）における優先度付けでは、悪用実績のある業界固有の脅威インテリジェンスを反映させることが重要である。

**参照**: [Help Net Security](https://www.helpnetsecurity.com/2026/08/12/august-2026-patch-tuesday-cve-2026-68820/) / [GCN](https://gcn.com/windows-zero-day-north-korea-lazarus/20774/) / [SecurityWeek](https://www.securityweek.com/august-2026-patch-tuesday-microsoft-fixes-421-cves-one-exploited-zero-day/)

## 3. Microsoft QUICの未認証RCE脆弱性（CVE-2026-62815、CVSS 9.8）

**概要**: 8月度Patch Tuesdayでは、Microsoft QUICプロトコル実装に存在するUse-After-Free脆弱性CVE-2026-62815（CVSS 9.8）も修正された。認証不要のリモート攻撃者によるコード実行が可能とされる重大な脆弱性である。同時に、Windows Deployment Services TFTPサーバーの脆弱性CVE-2026-62893（CVSS 9.8、「悪用可能性が高い」と評価）も公表され、リモート未認証攻撃者によるコード実行のリスクが指摘されている。現時点では両脆弱性とも実際の悪用は確認されていないが、CVSS 9.8という最高水準のスコアと未認証でのリモート実行という条件から、パッチ未適用環境は早急な対応が求められる。QUICはHTTP/3等で使われる比較的新しいトランスポート層プロトコルであり、実装の複雑さが脆弱性の温床になりやすいとの指摘もある。

**関連CBKドメイン**: ドメイン4（通信とネットワークセキュリティ）／ドメイン6（セキュリティの評価とテスト）

**コラム**: QUICのような新しいプロトコルスタックは、TCP/TLSに比べて実装コードベースが新しく、枯れていないため脆弱性が発見されやすい傾向がある。ネットワークセキュリティ担当者は、新プロトコル導入時にプロトコルスタックの成熟度・パッチ履歴を評価基準に含めるべきである。また未認証RCEは境界防御が破られた場合の影響が甚大であり、Patch Tuesdayの月次サイクルに依存しない緊急パッチ適用プロセス（CVSS 9.0以上は即日〜数日以内）をあらかじめ定義しておくことが、セキュリティ運用の成熟度を左右する。

**参照**: [Tenable](https://www.tenable.com/blog/microsofts-august-2026-patch-tuesday-addresses-398-cves-cve-2026-68820) / [CrowdStrike](https://www.crowdstrike.com/en-us/blog/patch-tuesday-analysis-august-2026/)

## 4. SonicWall SMA1000のゼロデイ連鎖悪用、INC Ransomwareが主導

**概要**: SonicWallのSMA1000シリーズ（VPNアプライアンス）に存在する2件の脆弱性、CVE-2026-15409（CVSS 10.0）とCVE-2026-15410（CVSS 7.2）が連鎖的に悪用され、未認証のリモート攻撃者がroot権限を奪取できる状態にあったことが判明した。CVE-2026-15409は/wsproxyの認証前バイパスで、本来localhostからのみアクセス可能なサービスへWebSocketトンネルを開くことを許してしまう欠陥。CVE-2026-15410はctrl-serviceのremove_hotfixワークフローにおけるパストラバーサルで、低権限サービスアカウントからrootへの昇格に悪用される。両脆弱性は脅威アクター「UTA0533」により、公表前の2026年6月22日から悪用されていたことが確認されており、SonicWallは7月中旬に修正パッチを提供した。その後、INC Ransomwareグループがこの脆弱性連鎖を用いた侵害の大半を占める主要な攻撃者として台頭し、認証情報やアクティブセッションデータベース、TOTP多要素認証のシード情報まで窃取して長期的な持続アクセスと内部ネットワークへの水平移動を図っていることが、Resecurity等の報告で明らかになっている。

**関連CBKドメイン**: ドメイン4（通信とネットワークセキュリティ）／ドメイン5（アイデンティティおよびアクセス管理）

**コラム**: VPNゲートウェイのような境界防御装置自体が侵害の起点となる事例は近年頻発しており、境界機器を「信頼できる防御層」として無条件に扱うことのリスクを示している。特に注目すべきは、攻撃者がTOTP MFAのシード情報まで窃取している点である。これはMFAが「導入していれば安全」という単純な図式ではなく、シード情報や認証基盤自体が侵害された場合はMFAも無力化されうることを意味する。CISSP実務者は、境界機器のパッチ管理に加え、MFAシードのローテーションやハードウェアトークンへの移行、侵害後の認証情報全体の失効・再発行プロセスをインシデント対応計画に組み込む必要がある。

**参照**: [The Hacker News](https://thehackernews.com/2026/08/inc-ransomware-emerges-as-dominant.html) / [Resecurity](https://www.resecurity.com/blog/article/from-wsproxy-to-root-inc-ransomware-and-sonicwall-sma-exploit-chain) / [Tenable](https://www.tenable.com/blog/cve-2026-15409-cve-2026-15410-sonicwall-sma-1000-zero-day-vulnerabilities-exploited-in-the)

**概要**: ロシア系ランサムウェアグループClopは8月13日前後、シェル（Shell）やフィリップス（Philips）を含む43社以上の新規被害者をダークウェブのリークサイトに掲載したと報じられている。Clopの主張によれば合計で約50社からデータを窃取しており、Shellからは89GBものデータ（設計図面、施設テスト報告書のスキャン、施設の写真、プロジェクト計画書等）を持ち出したとしている。攻撃は、インターネットに露出したPTC WindchillおよびFlexPLM（製品ライフサイクル管理ソフトウェア）環境を狙ったものとみられ、入力検証不備の脆弱性CVE-2026-12569との関連が指摘されている。Shell側は「潜在的インシデントを認識しており調査中」とコメントしている。Clopは2023年のMOVEit Transfer大規模侵害でも同社を標的にしており、ファイル転送・PLM等のエンタープライズソフトウェアを狙う手口を繰り返し用いている点が特徴である。

**関連CBKドメイン**: ドメイン8（ソフトウェア開発セキュリティ）／ドメイン1（セキュリティとリスクマネジメント）

## 6. Ransom Cartel創設者に禁錮16年の判決、RaaSオペレーターへの摘発が進展

**概要**: バージニア州アレクサンドリアの連邦判事は8月5日、ランサムウェア・アズ・ア・サービス（RaaS）「Ransom Cartel」を2021年に立ち上げ運用していたMaksim Silnikau被告に対し、禁錮16年の判決を言い渡した。Ransom Cartelは、被害企業のシステムを暗号化し身代金を要求する典型的なRaaSモデルで運営され、アフィリエイト（実行犯）に攻撃ツールと基盤を提供し、身代金の一部を対価として得る仕組みだったとされる。今回の量刑は、ランサムウェアの開発・運用に関与した個人に対する司法当局の摘発・訴追が着実に進んでいることを示す事例である。

**関連CBKドメイン**: ドメイン1（セキュリティとリスクマネジメント）

**コラム**: RaaSモデルの摘発は、攻撃者側の抑止力として一定の意味を持つが、開発者個人の摘発が直ちにエコシステム全体の縮小につながるわけではなく、アフィリエイトは別のRaaSへ移行するのが一般的である。CISSP実務者にとっての教訓は、法執行機関の摘発ニュースを「脅威が減った」と楽観視する材料にせず、引き続きランサムウェア対策（バックアップ、セグメンテーション、インシデント対応計画）を継続する必要があるという点である。またこうした事例は、法規制・コンプライアンス・サイバー犯罪の国際的な捜査協力の実態を学ぶ上でも有用な参考情報となる。

## 用語解説

- **CVE（Common Vulnerabilities and Exposures）**: 個々の脆弱性に一意の識別番号を付与する共通脆弱性識別子。業界横断で脆弱性を一意に特定・共有するための標準。
- **CVSS（Common Vulnerability Scoring System）**: 脆弱性の深刻度を0〜10の数値で評価する共通指標。攻撃条件（ネットワーク経由か、認証が必要かなど）と影響度（機密性・完全性・可用性）から算出される。
- **ディレクトリトラバーサル（パストラバーサル）**: 本来アクセスが許可されていないディレクトリ・ファイルに、相対パス指定（「../」等）を悪用してアクセスする攻撃手法。
- **Use-After-Free（解放済みメモリの再利用）**: 一度解放されたメモリ領域を、別のコードが誤って参照・使用してしまうことで発生するメモリ破損の脆弱性。任意コード実行や権限昇格に悪用されやすい。
- **RCE（Remote Code Execution：リモートコード実行）**: ネットワーク越しに攻撃者が対象システム上で任意のコードを実行できてしまう脆弱性・攻撃の総称。
- **ゼロデイ（0-day）**: ベンダーが修正パッチを提供する前、あるいは脆弱性の存在が公になる前の段階で悪用される脆弱性・攻撃のこと。
- **権限昇格（Privilege Escalation）**: 攻撃者が本来与えられている以上の権限（一般ユーザーからSYSTEM/root権限など）を不正に取得する行為。
- **APT（Advanced Persistent Threat：高度で持続的な脅威）**: 国家の関与が疑われるなど、高度な技術力と潤沢なリソースを持ち、長期間にわたり標的組織に潜伏し続ける攻撃者・攻撃活動を指す。
- **RaaS（Ransomware as a Service）**: ランサムウェアの開発者が攻撃基盤・ツールを「サービス」としてアフィリエイト（実行犯）に提供し、身代金の一部を対価として得るビジネスモデル。
- **MFA（Multi-Factor Authentication：多要素認証）**: パスワードに加え、ワンタイムコードや生体情報など複数の要素を組み合わせて本人確認を行う認証方式。
- **TOTP（Time-based One-Time Password）**: 一定時間ごとに変化するワンタイムパスワードを用いる方式。MFAの実装でよく使われる。
- **WebSocketトンネル**: WebSocketプロトコルを用いて、本来直接アクセスできないネットワークセグメントやサービスへの通信経路を確立する技術。攻撃では不正な迂回経路の確立に悪用される。
- **PLM（Product Lifecycle Management：製品ライフサイクル管理）**: 製品の設計・開発から廃棄までの情報を一元管理するソフトウェア・手法。設計図面など機密性の高い情報を含むため攻撃対象になりやすい。
- **サプライチェーンリスク**: 自社が直接管理しないソフトウェアベンダーや委託先、取引先を経由して発生するセキュリティリスク。近年のランサムウェア攻撃で頻繁に悪用される経路。
- **アタックサーフェス（攻撃対象領域）**: 攻撃者が侵入・攻撃を試みることができる、システムやネットワークの露出箇所全体を指す概念。露出を最小化することがリスク低減の基本。
- **インシデント対応（Incident Response）**: セキュリティ侵害を検知した後の、封じ込め・根絶・復旧・事後分析までの一連のプロセス。CISSPドメイン7の中核テーマの一つ。
- **QUIC**: UDPをベースとした次世代トランスポート層プロトコル。HTTP/3などで採用されており、低遅延通信を実現する一方、実装の複雑さから脆弱性が発見されやすい側面もある。
