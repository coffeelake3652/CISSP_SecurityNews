## 1. PHP「PHP2Shell」: CVE-2026-109618 / CVE-2026-109619 の実攻撃が確認、ファイアウォール製品経由で侵害

**概要**
PHP Groupは2026-10-20に「Upcoming Critical PHP Security Release」として事前予告を出し、2026-10-21にPHP 8.5.12 / 8.4.27 / 8.3.36 / 8.2.35を公開、認証不要でRCEが可能な2件の脆弱性（CVE-2026-109618: OOM後の不完全な初期化、CVE-2026-109619: 古い内部リクエスト状態の残存）を修正した。影響はPHP-FPM、Apache mod_php、php-cgi、FrankenPHP、LiteSpeedで、特にmod_phpはアプリコード実行前に攻撃可能とされる。PHP 8.1以前（EOL）には修正版が提供されず、最小限の緩和策のみが示された。10-23には別件CVE-2026-115560（特定設定・コードの組み合わせで発生、修正未提供）も公表された。JPCERT/CCは10-22に注意喚起（AT-2026-0033）を出し、10-29に更新、PoCの公開と攻撃通信を確認している。The Recordによれば、Dream社の報告ではPHP2Shellをファイアウォールの初期侵入に使い、Linuxの権限昇格（CVE-2026-46300、KEV追加済）と連鎖させて完全制御を得た事例があり、ベンダーは後にPalo Alto Networksと特定、Unit 42が管理Webサーバの修正版を公開した。攻撃の大半は10-23〜24で、約19,000台のFW候補から240台に絞り込み、24台で侵害（うち22台はWebシェル設置のみ）、GreyNoiseは少なくとも6件の成功を確認。Dreamは中国系と推定（単一情報源の見立て）。両CVEはCISA KEVに追加済と報じられている。

- 関連CBKドメイン: ドメイン8（ソフトウェア開発セキュリティ）、ドメイン7（セキュリティ運用）、ドメイン3（セキュリティアーキテクチャとエンジニアリング）
- コラム: ランタイム自体の脆弱性は、アプリ側のコード品質とは無関係に全層へ波及するため、ドメイン8のサプライチェーン／ライブラリ管理とドメイン7のパッチ・脆弱性管理の双方が問われる。「PHPは自社では使っていない」と思っていても、FWや管理アプライアンスに同梱されている点が教訓である。EOL版（8.1以前）には修正が出ないため、資産台帳（ドメイン2）でバージョンを把握し移行計画を持つことが必要。暫定策の `session.upload_progress.enabled=0` は恒久対策ではなく、侵害調査（異常に長いPHPSESSID、multipart/form-dataの異常、PHPワーカー再起動頻発）も並行して行うべきである。
- 参照: [JPCERT/CC AT-2026-0033](https://www.jpcert.or.jp/at/2026/at260033.html) / [php.net 2026アーカイブ](https://www.php.net/archive/2026.php) / [The Record](https://therecord.media/php2shell-successful-exploitation-reports-emerge) / [Let's Data Science](https://letsdatascience.com/news/ai-discovered-php-flaws-force-governments-and-companies-to-t-92f5dbbe)

## 2. Brotli「Node2Shell」CVE-2026-111497: 実悪用とKEV追加、.NET・Node.jsなど広範囲に影響

**概要**
GoogleのBrotli（C実装）デコーダに境界外書き込みの脆弱性（CVE-2026-111497）があり、悪意あるBrotli圧縮データの処理でクラッシュ、メモリ漏えい、任意コード実行が起こり得る。影響はBrotli 1.2.0〜1.2.1未満、1.1.0〜1.1.1未満、1.0.3〜1.0.10未満で、修正は1.2.1 / 1.1.1 / 1.0.10。Help Net Securityによれば修正自体は2026-02-27にgoogle/brotliへコミットされていたがリリース・告知がなく、2026-10-21にNode.jsが公表し26.12.1 / 24.22.1 / 22.23.4を公開した。MicrosoftはOct 25に.NET 8/9/10の臨時更新（8.0.33、9.0.22、10.0.14）を出した（CSO Online）。Bun、Envoy、Istio、Python HTTPクライアント、FFmpeg、Apache Arrow、ClickHouseなども影響対象と報じられる。ELLIOが悪用通信（送信元94.154.43.7）を観測し、10-28にCISA KEVへ追加されたと更新記事にあるが、CSO Online記事は公開時点で悪用未報告としており、情報源間で時点が異なる。Imperva等がNode.js公式イメージに対するRCEを実証し、PoCはGitHubで公開されている。JPCERT/CC（AT-2026-0034）は10-26に注意喚起。CVSSは参照記事に記載がなく未確認。Self-contained / Native AOTのアプリは共有ランタイム更新だけでは直らず再ビルドが必要。

- 関連CBKドメイン: ドメイン8、ドメイン7、ドメイン2
- コラム: 圧縮ライブラリのような「見えない依存関係」がHTTP経路から直接攻撃面になる典型例で、SBOMによる組み込み箇所の把握（ドメイン8・2）が前提となる。修正が数か月前にコミットされながら告知されなかった点は、OSS依存におけるリスク評価（ドメイン1）で「修正コミット≠利用可能な修正」と認識すべきことを示す。.NETのSelf-contained配備は再ビルド・再配備が必要で、変更管理（ドメイン7）の実効性が問われる。

## 3. GitLab CE/EE CVE-2026-97229（CVSS 10.0）と Cisco ASA/FTD CVE-2026-76418がCISA KEVに追加

**概要**
CISAは2026-10-29、GitLab CE/EEの整数オーバーフロー（CVE-2026-97229、CVSS 10.0、認証不要でCI/CD設定内の細工した正規表現からRCE）とCisco Secure Firewall ASA/FTDのNULLポインタ参照によるDoS（CVE-2026-76418、CVSS 8.6）をKEVに追加した。連邦機関の対処期限は11月1日。GitLabについてはAlpine Linuxが10-20〜21に自社インスタンスへの攻撃を開示：細工したCI設定でワーカーを8回クラッシュさせ（4回は次段階で失敗）、コンテナイメージを取得、10-25〜26に再侵入を試みたがブロックされた。侵害の証拠はないが完全否定できないため再構築し、aports・パッケージ・10-21リリースの改ざんはないと報告。CERT-EUも10-12と10-22にGitLabの重大脆弱性アドバイザリ（2026-016、2026-019）を出している。CiscoはCVE-2026-76418の悪用を10月に認識、SSL VPN有効かつトンネルグループでセカンダリ認証が有効な構成が対象で、Shadowserverは5万1千台超のASA SSL VPNを露出と計測（CISO Platform経由）。修正版はASA 9.18.4.96等、FTD 7.2.13等。ワークアラウンドはなく、セカンダリ認証無効化が暫定緩和（単一の二次報道）。攻撃者は不明。8月にも別のASA/FTD DoSゼロデイ（CVE-2026-20349）が悪用されている。

- 関連CBKドメイン: ドメイン7、ドメイン3、ドメイン4
- コラム: ソースコード管理／CI基盤は「ビルドの信頼の根」であり、侵害されるとサプライチェーン全体に波及するため、Alpineが再構築と成果物の完全性検証を行った判断は模範的である（ドメイン7・8）。境界FWのDoSは単なる可用性問題に見えるが、再起動を突いた二次攻撃や冗長構成の検証にもつながり、可用性もCIAの一角として扱う（ドメイン1・4）。KEV期限を自社SLAの基準に取り込む運用を推奨。
- 参照: [The Hacker News](https://thehackernews.com/2026/10/cisa-adds-actively-exploited-gitlab-rce.html) / [CERT-EU](https://cert.europa.eu/publications/security-advisories/) / [CISO Platform](https://www.cisoplatform.com/profiles/blogs/breach-watch-cisco-firewall-zero-day-volt-typhoon)

## 4. Binance、約63億ドル規模のセキュリティインシデント（史上最大の暗号資産窃取、北朝鮮関与の見立て）

**概要**
Binanceは2026-10-30までに、約63億ドル相当の資産に影響するセキュリティインシデントを公表した。Chainalysisは窃取時点で約59億ドル、Elliptic は64.3億ドルと推計し、2025年2月のBybit事件（約15億ドル）を上回る過去最大とされる。1回の送金でホットウォレットから167,464 ETH、63種のトークン、16.15億USDTが攻撃者アドレスへ移動した。初期調査ではDevOpsエンジニアのノートPCが侵害され、サービスコンテナ経由で不正出金が申請されたとされるが、その後「追加の侵害箇所」が判明し、秘密鍵漏えいの証拠はないとしている。TRM Labsは攻撃者が約50件の事前署名済み承認を準備し、準備は実行の少なくとも36時間前から始まっていたと分析。TetherとCircle等が合計約26.7億ドルのステーブルコインを凍結、Ellipticの凍結総額は約28.4億ドル。TRM LabsとChainalysisは北朝鮮（TraderTraitor）と高い確度で帰属するが、Ellipticは手法の差異から慎重な姿勢で、根本原因は未公表。Binanceは入出金を停止し、SAFU基金等で補填、約48時間後の再開を見込む。

- 関連CBKドメイン: ドメイン1、ドメイン5、ドメイン7
- コラム: 特権端末の侵害から高額出金に至る経路は、職務分離・多重承認・特権アクセス管理（ドメイン5）の実効性が問われる典型である。事前署名済み承認が準備されていた点は、承認の有効期限・ナンス管理・異常検知（ドメイン7）の設計課題を示す。巨額損失に対する補填余力とインシデント対応・事業継続計画（ドメイン1・7）は、リスク受容額の妥当性を検証する材料になる。帰属は機関間で見解が分かれるため断定を避ける。
- 参照: [The Hacker News](https://thehackernews.com/2026/10/binance-suffers-security-breach.html)（単一情報源、他社見解も同記事内）

## 7. Linux kernel TCPの競合状態 CVE-2026-98432（kernel CNA 9.8）: 主要ディストリ修正が遅延中

**概要**
Linux 4.4で混入したIPv4 TCP接続確立時の競合状態によるUse-after-free（IPv6は非該当）。Kernel CVEチームはCVSS 9.8（10-24追加）とするが、Red Hatは5.9（Moderate）、Red Hat advisory・Oracle・SUSEは8.1、Amazon Linuxは7.0と評価が割れている。上流修正は10-5、修正版カーネルは5.10.272、5.15.223、6.1.190、6.6.159、6.12.113、6.18.56、7.2.10、7.3。Anthropicは自社AIモデルがMPTCPリスナを持つサーバでKASLR回避（約48分）から追加約5分でroot権限コマンド実行に至る悪用を構築したと述べる（コード非公開）。10-29時点で野良の悪用は未報告でKEVにも未掲載。パッチ状況はOracle Linux・Debian trixie・Amazon Linux 2023の一部が修正済み、Ubuntu（16.04〜26.10）とRHEL 8/9/10は未修正（Ubuntuは優先度High）。ディストリ間で修正が非同期のため、カーネル更新の適用判断に時間差が生じる。

- 関連CBKドメイン: ドメイン7、ドメイン3
- コラム: 同一脆弱性に対する重大度評価が9.8〜5.9と乖離する場合、CVSSの数値のみでリスク判断せず、自社構成（MPTCP有効化の有無等）に基づくリスク分析（ドメイン1）が必要となる。修正が出揃うまでの間はカーネルパラメータやネットワーク制御による補完統制を検討し、パッチ管理（ドメイン7）のSLAと例外管理を明確にする。単一情報源（The Hacker News）の報道である点に留意。
- 参照: [The Hacker News](https://thehackernews.com/2026/10/linux-kernel-tcp-flaw-with-98-cvss.html)

## 用語解説

- **KEV（Known Exploited Vulnerabilities）**: CISAが管理する、実際に悪用が確認された脆弱性のカタログ。連邦機関は期限内の対処が義務付けられる。
- **RCE（Remote Code Execution）**: 遠隔から任意のコードを実行される脆弱性。
- **CVE / CVSS**: CVEは脆弱性の識別番号、CVSSは深刻度を0〜10で示す共通評価尺度。
- **PoC（Proof of Concept）**: 脆弱性が悪用可能であることを示す実証コード。
- **EOL（End of Life）**: ベンダーのサポートが終了し、修正が提供されなくなった状態。
- **mod_php / PHP-FPM**: PHPをWebサーバで動かす方式（ApacheモジュールとFastCGIプロセスマネージャ）。
- **Webシェル**: 侵害したサーバに設置し、遠隔からコマンドを実行するための不正スクリプト。
- **権限昇格**: 低い権限で侵入した攻撃者が、管理者権限などを得ること。
- **ラテラルムーブメント（横展開）**: 侵入後に内部ネットワークの別の機器へ攻撃を広げること。
- **Brotli**: Googleが開発したデータ圧縮方式で、HTTP通信で広く使われる。
- **境界外書き込み（Out-of-Bounds Write）**: メモリの確保範囲外へ書き込むバグで、コード実行につながり得る。
- **SBOM**: ソフトウェアに含まれる部品・ライブラリの一覧。依存関係の把握に使う。
- **Native AOT / Self-contained**: .NETの配備形態で、ランタイムをアプリに内包するため、共有ランタイム更新だけでは修正が反映されない。
- **整数オーバーフロー**: 整数が表現可能な範囲を超えて値が回り込み、想定外の動作を起こすバグ。
- **NULLポインタ参照**: 無効なメモリアドレスを参照してプログラムやデバイスが異常終了するバグ。
- **SSL VPN**: SSL/TLSを使った遠隔接続用VPN。境界機器の攻撃対象になりやすい。
- **CI/CD**: ソフトウェアのビルド・テスト・配備を自動化する仕組み。
- **ホットウォレット**: インターネット接続状態で秘密鍵を扱う暗号資産ウォレット。
- **TraderTraitor**: 暗号資産窃取を行う北朝鮮系とされる攻撃グループ。
- **SAFU基金**: Binanceが不測の損失に備えて積み立てる補填用の基金。
- **NoSQLインジェクション**: NoSQLデータベースへの問い合わせに不正な入力を混入させる攻撃。
- **SQLインジェクション（SQLi）**: 入力値を悪用してデータベースを不正操作する攻撃。
- **Tor出口ノード / レジデンシャルプロキシ**: 通信元を匿名化・分散させるための経路。攻撃元の特定を難しくする。
- **BI（Business Intelligence）ツール**: 社内データを分析・可視化するツール。Metabaseなど。
- **ShadowPad / BLOODALCHEMY**: 中国系攻撃者が使うモジュール型バックドアとその派生。
- **SAML / XXE**: SAMLはシングルサインオン用の認証連携方式、XXEはXML外部実体参照を悪用する攻撃。
- **IMDS**: クラウド仮想マシンの認証情報等を提供するメタデータサービス。IMDSv2は防御強化版。
- **LAPS / RBCD**: LAPSはローカル管理者パスワード管理機能、RBCDはAD上で代理認証を許す制約付き委任の仕組みで、悪用されると権限なりすましに使われる。
- **KASLR**: カーネルのアドレス配置をランダム化して攻撃を難しくする防御機構。
- **Use-after-free**: 解放済みメモリを参照し続けるバグで、情報漏えいやコード実行につながる。
- **MPTCP**: 複数経路を同時に使えるTCPの拡張規格。
- **競合状態（Race Condition）**: 処理のタイミング次第で結果が変わり、脆弱性になるバグ。
- **CNA**: CVE番号を割り当てる権限を持つ組織。
- **IPv4 / IPv6**: インターネットで使われるアドレス方式。
- **職務分離**: 重要な作業を複数人に分け、単独での不正を防ぐ統制。
- **SOHO機器**: 小規模オフィスや家庭向けのルータ等。踏み台に悪用される。
- **ランサムウェア**: データを暗号化して身代金を要求するマルウェア。
- **ゼロデイ**: 修正が提供される前に悪用される脆弱性。
- **MSP**: 顧客のIT運用を請け負う事業者。侵害されると顧客へ波及する。
- **AIペネトレーションテストツール**: AIが脆弱性探索や攻撃を自動化するツール。攻撃にも悪用される。
